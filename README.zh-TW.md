# SwitchGuard

SwitchGuard 會監控你自己的 **eWeLink / SONOFF** 與 **Tuya / Smart Life** 帳號中的智慧插座和開關，一有變化就立即發出真正的警報——抽水馬達停了、冷凍櫃插座被關掉、裝置斷線了。可在 Android 手機、平板、Android TV 與 Wear OS 手錶上執行，另外也有 Windows 應用程式。

## 下載

### Android (手機、平板、電視)
- **Google Play**: https://play.google.com/store/apps/details?id=com.macerce.switchguard
- **APK**: [最新 Android 版本](https://github.com/Macerce/switchguard/releases/latest) — 下載 `SwitchGuard-x.y.z.apk` 並在手機上開啟。如果已從 Google Play 安裝 SwitchGuard，請先解除安裝（簽章不同）。GitHub 版本會在有新版時通知你。

### Windows 10 / 11
- **安裝程式**: [Windows 版本](https://github.com/Macerce/switchguard/releases?q=Windows&expanded=true) — 從最新版本下載 `SwitchGuard-x.y.z-Kurulum.exe` 並執行。應用程式會自行尋找新版本並一鍵更新；設定會保留。

### 免費
- 在 Android 和 Windows 上完全免費 — 所有功能、監控所有裝置、無需購買、無需授權金鑰。使用示範裝置無需硬體即可體驗所有功能。

## 系統需求

- Android 8.0+（API 26）；手錶應用程式需要 Wear OS
- eWeLink：一個免費的 eWeLink 開發者應用程式（App ID + App Secret）——應用程式內的指南會一步步帶你完成。eWeLink 每個帳號和 App ID 只允許一個工作階段，因此每支手機、平板、電視或電腦都需要自己的 eWeLink 帳號，並將裝置分享給它 ([dev.ewelink.cc](https://dev.ewelink.cc))
- Tuya / Smart Life：你自己的免費 Tuya Cloud 專案的 Access ID 與 Access Secret，並已連結你的 Smart Life / Tuya 應用程式帳號 ([platform.tuya.com](https://platform.tuya.com))
- Windows 應用程式需要 Windows 10 / 11（64 位元）

## 功能

### 監控與警報

- 透過 eWeLink WebSocket 與 Tuya 訊息服務即時更新，並以 HTTP 重新同步和定期檢查作為備援。
- 警報會一直響到你關閉為止——即使在靜音模式下——並在鎖定畫面上全螢幕開啟；每台裝置都可以有自己的鈴聲。
- 依裝置設定規則：裝置關閉、開啟、離線或恢復連線時，發出警報、通知或不做任何事。
- 條件提醒：裝置持續開啟或關閉一段時間，或功率高於 / 低於某個門檻時響鈴（例如抽水馬達低於 50 W）。
- 忽略短暫斷線；監控本身停止時（無網路 / 雲端）發出警告；eWeLink 工作階段遺失時大聲提醒（例如同一帳號在另一支手機登入）。
- 就緒卡片會顯示並修正可能阻止警報的手機設定（電池限制、全螢幕權限、零打擾、鬧鐘音量……）。

### 裝置

- 智慧家庭風格的圖塊，附快速開關按鈕；多通道裝置每個通道一個按鈕；即時狀態與功率。
- 裝置頁面：規則、專屬警報鈴聲、提醒類別、用電歷史與費用、eWeLink 計時器、Wi-Fi 訊號與斷線診斷、待機耗電和最近事件。
- **排列裝置**: 星號 = 置頂 · 方向鍵 = 移動 · 卡片大小 = 小或大 · 標籤 = 分類。長按卡片即可回到此處。

### 感測器（eWeLink）

- 溫度 / 濕度（TH16, THR316/320, SNZB-02）、門窗（DW2, SNZB-04）、移動 / 人體存在（SNZB-03, SNZB-06P）、漏水（SNZB-05）及電池電量，顯示於裝置卡片、待機畫面和聊天中。
- 自動化中的感測器觸發條件（數值高於 / 低於、門被打開、偵測到移動、漏水），以及裝置頁面上一鍵開啟的感測器提醒。
- 感測器歷史：監控開啟時會儲存溫度、濕度、光照和電池讀數；裝置頁面顯示 24 小時 / 7 天 / 30 天圖表，含最低、最高和平均值。

### 警報

- 裝置提醒和條件提醒集中在一處，可依提醒類別篩選（緊急 / 重要 / 一般）。
- 提醒設定：警報鈴聲與音量、勿擾時段、提醒類別、Telegram（「通知其他人」）和智慧提醒——請見下方 *所有設定*。
- 智慧提醒：停電時只發一則提醒、異常用電、每月預算、每週報告、度假模式。

### 自動化

- **規則** — 自動動作：*如果* 發生某事，*就* 執行某個動作，可選延遲。
- 觸發條件: 開啟時, 關閉時, 持續開啟達, 持續關閉達, 離線時, 重新上線時, 功率超過, 功率降到低於, 日出時, 日落時, 室外溫度升到高於, 室外溫度降到低於, 抵達時, 離開時. 感測器觸發：數值高於 / 低於、門打開 / 關閉、偵測到移動、漏水。
- 動作: 開啟, 關閉, 觸發警報, 傳送通知, 執行情境, 開始循環, 停止循環.
- **僅當**: 僅在這些時段, 且僅當另一個裝置…, 僅在家 / 外出時. 條件也能檢查感測器數值、感測器狀態（門開著、偵測到移動、漏水）、裝置功率或室外溫度；可新增多個條件並選擇「全部符合」（且）或「符合任一即可」（或）。
- **情境** — 選擇情境執行時每個裝置會發生什麼事。保持「略過」的裝置不會被更動。
- **群組** — 選擇群組中的裝置。群組會像裝置一樣顯示在「裝置」畫面上：它的按鈕可一次開啟或關閉全部裝置，也可以用在自動化中。
- **循環與計時器** — 倒數計時, 先開再關, 開關循環, 逐一開啟, 自訂步驟. 可用按鈕啟動、在所選日子的固定時間啟動，或在某個時段內執行；可選隨機變化（營造有人在家的效果）以及「手動變更時停止」。
- 自動化會在監控開啟時於這支手機上執行。若排程需要在手機關機時也能運作，請使用裝置頁面上的計時器。

### 電能

- 依日 / 月 / 年檢視：總量、估計費用、平均與峰值功率、用電最多的小時/日/月，以及重點摘要。
- 單一費率或三段式費率（日間 / 尖峰 / 夜間），可依裝置設定電價或使用預設電價。
- 待機耗電（裝置從不低於的功率）及其每月費用。
- 用電報告可匯出為 PDF（列印或分享）或 CSV（Excel、Google 試算表）。
- 用電量是 SwitchGuard 根據監控開啟期間讀取的功率計算而來，因此可能與裝置製造商的應用程式（eWeLink、Smart Life）略有差異。

### 記錄

- 每個事件都附日期與時間，以及由誰或什麼觸發（應用程式、自動化）；可依裝置篩選。
- 匯出為 CSV（最近 24 小時、7 天、30 天或全部）以及清除歷史記錄。

### 聊天

- 您好。您可以用輸入的方式管理裝置：開啟或關閉、查詢狀態、用電量或室外溫度。點麥克風即可改用說的（「Turn off kitchen」）；回覆會以語音朗讀。下方有現成的範本；點一下即可傳送，長按可編輯。指令需使用英文或土耳其文。
- 自由文字指令可離線使用，支援英文和土耳其文；麥克風使用手機的語音辨識，回覆可以朗讀出來。
- 範本：一鍵送出的訊息，也可以每天在固定時間或發生某事時自動執行。

### 待機畫面

- 適用於充電中手機或平板的全螢幕看板：時鐘、天氣、緊急狀態、即時功率、近期活動，以及接下來會執行的項目。也會顯示在鎖定畫面上方。
- 會開啟 Android 設定：請在「螢幕保護程式」下選擇 SwitchGuard，並設為充電時啟動。這樣充電時看板就會取代鎖定畫面。

### 小工具、快速設定圖塊、捷徑

- **SwitchGuard** — 顯示監控是否正在執行，以及正在響鈴的警報
- **SwitchGuard 開關** — 點一下即可開啟或關閉單一裝置或迴路。也可以設定為 在家 / 外出 或執行某個情境。
- **SwitchGuard 群組** — 大型圖塊：個別開啟或關閉群組中的每個裝置
- **SwitchGuard 語音指令** — 一個圖塊：點一下，說出指令（「Turn off kitchen」），就會執行
- **快速設定圖塊**——顯示監控狀態，並可啟動或停止監控（需先解鎖手機）；警報響起時會開啟應用程式。
- **應用程式捷徑**——長按應用程式圖示即可使用 在家 / 外出 和你的情境。

### 在家 / 外出

- **在家 / 外出** — 標示為「僅外出時」的規則不會執行。離開時請切換為外出（也可從小工具、手錶或 Telegram 的 /away 切換）。
- **度假模式** — 視同外出、勿擾時段關閉，並且每天早上 09:00 會收到報告。到期後會自動結束。
- **區域** — 在地圖上選擇一個範圍；當您的手機進入或離開該範圍時，自動化就會執行（例如：到家時開啟庭院燈，離開時全部關閉）。地圖圖片從 OpenStreetMap 下載；您的位置只在這支手機上使用。

### Wear OS

- SwitchGuard 手錶應用程式會顯示警報（在手腕上關閉）、裝置（開關）、情境以及 在家 / 外出；它會連線到手機應用程式。

### Android TV

- 在 Android TV 上以遙控器操作；警報會顯示在正在播放的任何內容上方（「在其他應用程式上方顯示警報」）。
- 「從手機輸入」：電視顯示 QR 碼；你在手機上輸入金鑰，金鑰會經由家中 Wi-Fi 加密傳到電視。
- 「從另一個裝置接收」：透過 Wi-Fi 從手機複製 Tuya 金鑰、規則和設定。

### 多台裝置

手機、平板、Android TV 和電腦：**每台裝置都需要自己的 eWeLink 帳號（已核准開發者功能）以及該帳號自己的 API 金鑰（App ID / Secret）**——eWeLink 每個帳號只允許一台裝置登入。請在 eWeLink 應用程式中將裝置分享給額外的帳號。Tuya 金鑰可在多台裝置上使用。詳情： [English](docs/guide/ewelink.en.md#using-several-devices-phone-tablet-android-tv) · [Türkçe](docs/guide/ewelink.tr.md#birden-fazla-cihazda-kullanım-telefon-tablet-android-tv)

### 示範

- **示範裝置** — 可試用所有功能的虛擬裝置。這些操作會模擬裝置本身發生了狀況（有人操作了開關、斷電或 Wi-Fi 中斷），因此您的規則會生效，警報也可能響鈴。用上方按鈕操作視同您本人操作，不會觸發警報。

## 所有設定

以下內容皆依應用程式中的順序排列。**設定** 分頁包含連線與應用程式選項；警報、勿擾時段、Telegram 和智慧提醒位於 **警報** 分頁 → 提醒設定；各裝置的選項在其裝置頁面中。

### 設定 → 帳號

| 設定 | 用途 |
|---|---|
| eWeLink — 使用 eWeLink 登入 | 開啟 eWeLink 自己的登入頁面；應用程式永遠看不到你的密碼。 |
| API 憑證 | 你的 eWeLink 開發者應用程式的 App ID、App Secret 和區域。 |
| 登出 | 監控將會停止。您的設定和記錄會保留。 |
| Tuya / Smart Life | 請輸入您 Tuya Cloud 專案的 Access ID 和 Access Secret（platform.tuya.com → Cloud → 您的專案 → Overview）。您的 Smart Life / Tuya 應用程式帳號必須已連結到該專案。資料中心: Central Europe（中歐）, Western America（美國西部）, China（中國）, India（印度） |
| 中斷連線 | 移除 Tuya 連線；Tuya 裝置將不再受監控。 |
| 示範裝置 | 可試用所有功能的虛擬裝置 |

### 設定 → 監控

SwitchGuard 如何在背景持續監看您的裝置。

| 設定 | 用途 |
|---|---|
| 最高可靠度 | 讓處理器保持喚醒，確保不會延遲任何事件。會消耗較多電量。 |
| 忽略短暫斷線 | 裝置離線時，先等待這段時間再提醒。若在時間內恢復連線，就不會發出提醒。 |
| 監控停止時發出警告 | 沒有網路或雲端連線達這段時間時：您會收到警告 |
| 備援檢查間隔 | 僅在無法使用即時更新時使用。 |

### 設定 → 權限

沒有這些權限，Android 可能會讓警報無法送達給您。

| 設定 | 用途 |
|---|---|
| 通知 | 無法顯示警報和警告。 |
| 背景活動 | 手機可能會讓監控進入休眠；警報可能延遲或漏掉。 |
| 全螢幕警報 | 手機鎖定時，警報無法開啟其大畫面。 |
| 鎖定畫面警報（小米） | 手機鎖定時，警報畫面無法開啟。請點「修正」，開啟「其他權限」，並開啟「在鎖定螢幕上顯示」和「在背景執行時開啟新視窗」。 |
| 在其他應用程式上方顯示警報 | 在 Android TV 上需要此權限，警報才能顯示在正在播放的內容上方。點一下並允許 SwitchGuard。 |
| 背景啟動（Xiaomi, Huawei, OPPO, vivo…） | 在會阻擋背景啟動的手機上顯示（Xiaomi、Huawei、OPPO、vivo……）：讓監控在重新開機或更新後再次執行。請見「疑難排解」。 |

### 設定 → 位置與區域

| 設定 | 用途 |
|---|---|
| 位置 | 日出 / 日落和室外溫度規則所需。位置只會保留在此裝置上；查詢溫度時，會將四捨五入到約 100 公尺的位置傳送給 Open-Meteo。 |
| 區域 | 在地圖上選擇一個範圍；當您的手機進入或離開該範圍時，自動化就會執行（例如：到家時開啟庭院燈，離開時全部關閉）。地圖圖片從 OpenStreetMap 下載；您的位置只在這支手機上使用。 |

### 設定 → 待機畫面

| 設定 | 用途 |
|---|---|
| 開啟待機畫面 | 點一下畫面可看到「開啟應用程式」和「關閉」 |
| 用作螢幕保護程式 | 會開啟 Android 設定：請在「螢幕保護程式」下選擇 SwitchGuard，並設為充電時啟動。這樣充電時看板就會取代鎖定畫面。 |
| 夜間調暗 | 文字在 23:00 到 07:00 之間變暗 |

### 設定 → 每日摘要

| 設定 | 用途 |
|---|---|
| 每日摘要通知 | 今天每個裝置開啟了幾次、開啟多久，以及用了多少電 |
| 傳送時間 | 傳送摘要的時間。 |
| 立即顯示今天的摘要 | 立即顯示。 |

### 設定 → 備份與轉移

| 設定 | 用途 |
|---|---|
| 備份到檔案 | 規則、自動化、設定，以及 Tuya 和 eWeLink 金鑰會存入受密碼保護的檔案 |
| 從檔案還原 | 要換新手機嗎？選擇備份檔案並輸入其密碼 |
| 傳送到另一個裝置 | 將 Tuya 金鑰、規則和設定複製到同一 Wi-Fi 上的電視或平板 |
| 從另一個裝置接收 | 透過 Wi-Fi 從手機取得設定 |

Wi-Fi 傳輸絕不會傳送 eWeLink API 金鑰或 eWeLink 工作階段：請在另一台裝置上輸入它自己的 API 金鑰，並以它自己的 eWeLink 帳號登入。檔案備份則包含 eWeLink 與 Tuya 金鑰，並以你的密碼保護。

### 設定 → 語言

## Telegram 指令

名單中的人可以傳送 /status 並接手正在響的警報。警報訊息會附上「收到」按鈕：按下後手機就會靜音。

```
SwitchGuard 指令：
/status – 監控、警報和裝置
/ack – 接手正在響的警報
/on 名稱 [迴路] – 開啟裝置或群組（可多個：/on 廚房, 庭院）
/off 名稱 [迴路] – 關閉裝置或群組
/watt [名稱] – 目前、今天的功率與平常用電量
/temp – 室外溫度
/scene 名稱 – 執行情境
/home · /away – 設為在家 / 外出

您也可以自由書寫：「turn off kitchen and garden」、「heater watts」、「is the pump on」。

開關裝置和情境必須先在應用程式中允許（警報 → 智慧提醒）。
```

英文和土耳其文的指令名稱都可使用（例如 /status = /durum，/on = /ac）。只接受來自你所選聊天的指令。

## 疑難排解與常見問題

### 警報延遲或不響

| 問題 | 解決方法 |
|---|---|
| 背景活動受到限制 | 手機可能會讓監控進入休眠；警報可能延遲或漏掉。 |
| 不允許全螢幕警報 | 手機鎖定時，警報無法開啟其大畫面。 |
| 小米封鎖了警報畫面 | 手機鎖定時，警報畫面無法開啟。請點「修正」，開啟「其他權限」，並開啟「在鎖定螢幕上顯示」和「在背景執行時開啟新視窗」。 |
| 警報通知被調低了 | 「警報」通知類別未設為高優先順序，因此警報不會彈出或占滿螢幕。 |
| 勿擾模式：完全靜音 | 在此模式下，連警報音效也會被靜音。 |
| 警報音量非常低 | 手機的警報音量為零或接近零，您可能聽不到 SwitchGuard。按「修正」會開啟「以最大音量響鈴」。 |
| 通知已關閉 | 無法顯示警報和警告。 |
| 這支手機上有第二個 SwitchGuard | 已用手機的「應用程式雙開」（應用程式複製）功能建立了另一個 SwitchGuard 副本。兩個副本同時執行時，每個警報都會響兩次，且使用同一個 eWeLink 帳號時會互相登出；在小米手機上，此副本的權限也可能顯示為關閉。請移除第二個副本：長按其圖示（帶有小徽章的那個），然後點「解除安裝」。 |

### 其他問題

**監控停止了，並顯示我已登出。**  
提示：eWeLink 每個帳號只允許一個工作階段。請為每支手機各用一個 eWeLink 帳號，並從 eWeLink 應用程式分享裝置。

**別人分享給我的 Tuya 裝置沒有出現。**  
少了與您共享的裝置嗎？Tuya 只會列出您家庭中的裝置。請請擁有者在 Smart Life 中將您加為家庭成員（我 → 家庭管理 → 新增成員）。

**Tuya 裝置不再更新。**  
Tuya Cloud 試用期已到期，因此不會監控 Tuya 裝置。請到 platform.tuya.com → Cloud → IoT Core → Extend trial period 延長。

**變化很晚才到 / 無法使用即時更新。**  
此 App ID 無法使用即時更新，改用定期檢查（短於檢查間隔的變化可能會漏掉）

**可以在 Google Play 版和 GitHub 版之間切換嗎？**  
可以，但要先解除安裝另一個版本：兩者簽章不同。解除安裝前先備份到檔案，之後再還原。

**如何在不吵醒大家的情況下測試警報？**  
立即試用警報：有聲或靜音、立刻或 10 秒後

**為什麼用電量和 eWeLink / Smart Life 應用程式不同？**  
用電量是 SwitchGuard 根據監控開啟期間讀取的功率計算而來，因此可能與裝置製造商的應用程式（eWeLink、Smart Life）略有差異。

## Windows 應用程式

SwitchGuard for Windows（10 / 11）在電腦上進行同樣的監控：常駐系統匣，在電腦上全螢幕響起警報，並共用相同的規則、自動化和 Telegram 功能。區域、小工具、手錶和電話撥打僅限手機。

### 功能

- 相同的分頁：裝置, 警報, 自動化, 記錄, 聊天, 設定；聊天中的語音指令使用 Windows 語音輸入。
- 系統匣圖示：開啟、開始 / 停止監控、關閉警報、結束；關閉視窗不會停止監控。
- 全螢幕警報視窗，內建鈴聲（警笛, 嗶聲, 脈衝, 鐘聲）或你自己的 WAV / MP3。
- 待機畫面與 Windows 螢幕保護程式：電腦閒置時開啟看板。
- 插著充電器的筆電可作為停電感測器。
- 與手機相同的 eWeLink 感測器、感測器條件和感測器歷史。
- 一鍵從 GitHub 更新，設定會保留。可備份到受密碼保護的檔案（無法在手機上還原）。

### 僅限 Windows 的設定

| 設定 | 用途 |
|---|---|
| Windows | 讓 SwitchGuard 在這台電腦上不間斷地守護。只要有一項關閉，重新開機後或電腦睡眠期間就可能漏掉警報。 |

### 在 Windows 上安裝

1. 按兩下安裝檔（SwitchGuard-…-Kurulum.exe）。它不需要系統管理員權限，幾秒內即可裝好。
2. 如果 Windows 顯示「Windows 已保護您的電腦」（SmartScreen），請按其他資訊 → 仍要執行。應用程式尚未簽署，所以會有此警告。
3. SwitchGuard 安裝在你的使用者資料夾（AppData › Local › SwitchGuard）中，並在桌面和開始功能表新增捷徑。
4. 登入 Windows 時它會自動在系統匣（時鐘旁）啟動。關閉視窗不會停止它；要結束，請使用系統匣圖示 → 結束。
5. 在設定 → 帳號中新增你的帳號（Tuya 和 eWeLink 的步驟見下方）。
6. 搬到另一台電腦：在舊電腦上，設定 → 備份與轉移 → 備份到檔案；在新電腦上安裝後，從檔案還原，然後重新登入 eWeLink。
7. 解除安裝：Windows 設定 → 應用程式 → 已安裝的應用程式 → SwitchGuard → 解除安裝。
8. 安裝新版本：先解除安裝舊版本（第 7 步），再執行新的安裝檔。你的設定、帳號和音效會保留。（應用程式中的「更新」按鈕會自動完成此步驟。）
