# SwitchGuard

SwitchGuard는 내 **eWeLink / SONOFF** 및 **Tuya / Smart Life** 계정의 스마트 플러그와 스위치를 지켜보다가, 무언가 바뀌는 순간 진짜 알람을 울립니다. 멈춘 펌프, 꺼진 냉동고 플러그, 연결이 끊긴 기기 등. Android 휴대폰, 태블릿, Android TV, Wear OS 시계에서 실행되며 Windows 앱도 있습니다.

## 다운로드

### Android (휴대폰, 태블릿, TV)
- **Google Play**: https://play.google.com/store/apps/details?id=com.macerce.switchguard
- **APK**: [최신 Android 릴리스](https://github.com/Macerce/switchguard/releases/latest) — `SwitchGuard-x.y.z.apk`를 내려받아 휴대폰에서 여세요. Google Play에서 SwitchGuard를 이미 설치했다면 먼저 삭제하세요(서명이 다름). GitHub 버전은 새 버전이 나오면 알려 줍니다.

### Windows 10 / 11
- **설치 프로그램**: [Windows 릴리스](https://github.com/Macerce/switchguard/releases?q=Windows&expanded=true) — 최신 릴리스에서 `SwitchGuard-x.y.z-Kurulum.exe`를 내려받아 실행하세요. 앱이 새 버전을 직접 찾아 클릭 한 번으로 업데이트하며, 설정은 유지됩니다.

### 무료와 Pro
- Android: 완전 무료 — 모든 기능, 모든 기기 모니터링, 구매 없음. 데모 기기로 하드웨어 없이 모든 것을 체험할 수 있습니다.
- Windows 무료: 모든 기능을 모니터링 기기 1대에 사용할 수 있습니다.
- Windows: Pro 라이선스 키(설정 → 요금제 카드)로 모든 기기를 모니터링합니다. 키 문의: **switchguardapp@gmail.com**

## 요구 사항

- Android 8.0 이상(API 26), 시계 앱은 Wear OS
- eWeLink: 무료 eWeLink 개발자 앱(App ID + App Secret) — 앱 내 가이드가 단계별로 안내합니다. eWeLink는 계정과 App ID마다 세션을 하나만 허용하므로, 휴대폰·태블릿·TV·PC마다 기기를 공유받은 별도의 eWeLink 계정이 필요합니다 ([dev.ewelink.cc](https://dev.ewelink.cc))
- Tuya / Smart Life: Smart Life / Tuya 앱 계정에 연결된, 내 무료 Tuya Cloud 프로젝트의 Access ID와 Access Secret ([platform.tuya.com](https://platform.tuya.com))
- Windows 앱은 Windows 10 / 11(64비트)

## 기능

### 모니터링과 알람

- eWeLink WebSocket과 Tuya 메시지 서비스를 통한 실시간 업데이트, 예비로 HTTP 재동기화와 주기적 확인.
- 알람은 끌 때까지 계속 울리며(무음 모드에서도) 잠금 화면 위에 전체 화면으로 열립니다. 기기마다 다른 소리를 쓸 수 있습니다.
- 기기별 규칙: 기기가 꺼지거나, 켜지거나, 오프라인이 되거나, 다시 온라인이 될 때 알람, 알림 또는 없음.
- 조건부 알림: 기기가 일정 시간 켜지거나 꺼진 상태로 있거나, 전력이 기준보다 높아지거나 낮아지면 울립니다(예: 50 W 미만으로 도는 펌프).
- 짧은 연결 끊김 무시, 모니터링 자체가 멈추면 경고(인터넷 / 클라우드 없음), eWeLink 세션이 끊기면 큰 경고(예: 같은 계정이 다른 휴대폰에 로그인).
- 준비 상태 카드가 알람을 막을 수 있는 휴대폰 설정(배터리 제한, 전체 화면 권한, 방해 금지, 알람 볼륨…)을 보여 주고 고쳐 줍니다.

### 기기

- 스마트홈 스타일 타일: 빠른 전원 버튼, 다채널 기기는 채널마다 버튼, 실시간 상태와 전력.
- 기기 페이지: 규칙, 전용 알람 소리, 알림 카테고리, 전력 기록과 비용, eWeLink 타이머, Wi-Fi 신호와 끊김 진단, 대기 전력, 최근 이벤트.
- **기기 정렬**: 별 = 맨 위에 고정 · 화살표 = 이동 · 카드 크기 = 작게 또는 크게 · 태그 = 카테고리. 카드를 길게 누르면 여기로 돌아옵니다.

### 알림

- 기기 알림과 조건부 알림을 한곳에서, 알림 카테고리(긴급 / 주의 / 일반)로 필터링.
- 알림 설정: 알람 소리와 볼륨, 방해 금지 시간, 알림 카테고리, Telegram("다른 사람에게 알리기"), 스마트 알림 — 아래 *모든 설정* 참고.
- 스마트 알림: 정전 시 알림 한 건, 비정상 소비, 월 예산, 주간 보고서, 휴가 모드.

### 자동화

- **규칙** — 자동 동작: *만약* 무슨 일이 생기면 *그러면* 무언가를 실행(선택적 지연 포함).
- 트리거: 켜짐, 꺼짐, 켜진 상태가 지속됨:, 꺼진 상태가 지속됨:, 오프라인이 됨, 다시 온라인이 됨, 전력이 다음 값을 초과함:, 전력이 다음 값 아래로 떨어짐:, 일출 시, 일몰 시, 실외 온도가 다음 값을 넘을 때:, 실외 온도가 다음 값 아래로 떨어질 때:, 도착 시, 출발 시.
- 동작: 켜기, 끄기, 알람 울리기, 알림 보내기, 장면 실행, 사이클 시작, 사이클 중지.
- **다음 조건일 때만**: 이 시간대에만, 그리고 다른 기기가 다음 상태일 때만…, 재택 / 외출일 때만.
- **장면** — 장면이 실행될 때 각 기기에 어떤 동작을 할지 선택하세요. “건너뛰기”로 둔 기기는 건드리지 않습니다.
- **그룹** — 그룹에 포함할 기기를 선택하세요. 그룹은 기기 화면에 기기처럼 표시되며, 버튼 하나로 모두 함께 켜고 끌 수 있고 자동화에서도 사용할 수 있습니다.
- **사이클 및 타이머** — 카운트다운, 켠 뒤 끄기, 켜기/끄기 반복, 하나씩 차례로, 사용자 지정 단계. 버튼으로, 선택한 요일의 정해진 시각에, 또는 시간대 동안 시작. 선택적으로 무작위 변화(사람이 있는 것처럼)와 "수동으로 바꾸면 중지".
- 자동화는 모니터링이 켜져 있는 동안 이 휴대폰에서 실행됩니다. 휴대폰이 꺼져 있어도 작동해야 하는 일정에는 기기 페이지의 타이머를 사용하세요.

### 에너지

- 일 / 월 / 연 단위 보기: 합계, 예상 비용, 평균·최대 전력, 가장 많이 쓴 시간/일/월, 주요 내용 요약.
- 단일 요금 또는 3단계 요금(주간 / 피크 / 야간), 기기별 단가 또는 기본 단가.
- 대기 전력(기기가 결코 그 아래로 내려가지 않는 전력)과 월 비용.
- 전력 보고서를 PDF(인쇄·공유) 또는 CSV(Excel, Google 스프레드시트)로.
- 소비량은 모니터링이 켜져 있는 동안 측정한 전력 값으로 SwitchGuard가 계산하므로 기기 제조사 앱(eWeLink, Smart Life)과 약간 다를 수 있습니다.

### 기록

- 모든 이벤트를 날짜·시간과 누가/무엇이 바꿨는지(앱, 자동화)와 함께 기록, 기기별 필터.
- CSV 내보내기(최근 24시간, 7일, 30일 또는 전체)와 기록 지우기.

### 채팅

- 안녕하세요. 글을 써서 기기를 관리할 수 있습니다: 켜고 끄기, 상태, 전력 사용량, 실외 온도 확인. 마이크를 탭하면 말로 할 수도 있으며(“Turn off kitchen”) 답변을 소리 내어 읽어 줍니다. 아래에 준비된 템플릿이 있습니다. 탭하면 전송되고, 길게 누르면 편집할 수 있습니다. 명령은 영어 또는 튀르키예어로 입력합니다.
- 자유 문장 명령은 오프라인에서 작동하며 영어와 터키어를 이해합니다. 마이크는 휴대폰의 음성 인식을 사용하고, 답변은 소리 내어 읽어 줄 수 있습니다.
- 템플릿: 한 번 탭으로 보내는 메시지로, 매일 정해진 시각이나 무슨 일이 생겼을 때 자동으로 실행할 수도 있습니다.

### 대기 화면

- 충전 중인 휴대폰이나 태블릿을 위한 전체 화면 보드입니다: 시계, 날씨, 긴급 상태, 실시간 전력, 최근 활동, 다음 실행 예정. 잠금 화면 위에도 표시됩니다.
- Android 설정을 엽니다. 화면 보호기에서 SwitchGuard를 선택하고 충전 중에 시작하도록 설정하세요. 그러면 충전기에 연결된 동안 보드가 잠금 화면을 대신합니다.

### 위젯, 빠른 설정 타일, 바로가기

- **SwitchGuard** — 모니터링 실행 여부와 울리고 있는 알람을 표시합니다
- **SwitchGuard 스위치** — 탭 한 번으로 기기 또는 채널 하나를 켜고 끕니다. 재택 / 외출 전환이나 장면 실행용으로도 설정할 수 있습니다.
- **SwitchGuard 그룹** — 큰 타일: 그룹의 각 기기를 개별적으로 켜고 끕니다
- **SwitchGuard 음성 명령** — 타일 하나: 탭하고 말하면(“Turn off kitchen”) 실행됩니다. 영어 또는 튀르키예어로 말하세요
- **빠른 설정 타일** — 모니터링 상태를 보여 주고 모니터링을 시작하거나 멈춥니다(먼저 잠금 해제 필요). 알람이 울리는 중에는 앱을 엽니다.
- **앱 바로가기** — 앱 아이콘을 길게 누르면 재택 / 외출와 내 장면.

### 재택 / 외출

- **재택 / 외출** — "외출 시에만"으로 표시된 규칙은 실행되지 않습니다. 외출할 때 외출로 바꾸세요 (위젯, 워치 또는 Telegram /away로도 가능).
- **휴가 모드** — 외출로 간주되고, 방해 금지 시간이 꺼지며, 매일 아침 09:00에 보고서가 옵니다. 자동으로 종료됩니다.
- **구역** — 지도에서 영역을 선택하세요. 휴대폰이 그 영역에 들어가거나 나올 때 자동화가 실행됩니다 (예: 집에 도착하면 정원 조명 켜기, 외출하면 모두 끄기). 지도 이미지는 OpenStreetMap에서 다운로드되며, 위치 정보는 이 휴대폰에서만 사용됩니다.

### Wear OS

- SwitchGuard 시계 앱은 알람(손목에서 끄기), 기기(켜기/끄기), 장면, 재택 / 외출를 보여 주며 휴대폰 앱과 연결됩니다.

### Android TV

- Android TV에서 리모컨으로 작동하며, 알람은 재생 중인 모든 화면 위에 나타납니다("다른 앱 위에 알람 표시").
- "휴대폰에서 입력": TV에 QR 코드가 표시되고, 휴대폰에서 키를 입력하면 집 Wi-Fi를 통해 암호화되어 TV로 전송됩니다.
- "다른 기기에서 받기": Wi-Fi로 휴대폰에서 Tuya 키, 규칙, 설정을 복사합니다.

### 여러 기기

휴대폰, 태블릿, Android TV, PC: **기기마다 개발자 기능이 승인된 별도의 eWeLink 계정과 그 계정 자체의 API 키(App ID / Secret)가 필요합니다** — eWeLink는 계정당 로그인 기기를 하나만 허용합니다. eWeLink 앱에서 추가 계정에 기기를 공유하세요. Tuya 키는 여러 기기에서 쓸 수 있습니다. 자세히: [English](docs/guide/ewelink.en.md#using-several-devices-phone-tablet-android-tv) · [Türkçe](docs/guide/ewelink.tr.md#birden-fazla-cihazda-kullanım-telefon-tablet-android-tv)

### 데모

- **데모 기기** — 모든 기능을 체험해 볼 수 있는 가상 기기. 기기 자체에서 무언가 일어난 것처럼 동작합니다 (누군가 스위치를 조작했거나 전원 또는 Wi-Fi가 끊긴 경우). 그래서 규칙이 적용되고 알람이 울릴 수 있습니다. 위의 버튼으로 조작하면 사용자가 한 것으로 간주되어 알람이 울리지 않습니다.

## 모든 설정

아래 내용은 모두 앱에 표시되는 순서입니다. **설정** 탭에는 연결과 앱 옵션이 있고, 알람·방해 금지 시간·Telegram·스마트 알림은 **알림** 탭 → 알림 설정에 있습니다. 기기별 옵션은 각 기기 페이지에 있습니다.

### 설정 → 계정

| 설정 | 기능 |
|---|---|
| eWeLink — eWeLink로 로그인 | eWeLink 자체 로그인 페이지를 엽니다. 앱은 비밀번호를 절대 보지 않습니다. |
| API 자격 증명 | eWeLink 개발자 앱의 App ID, App Secret, 지역. |
| 로그아웃 | 모니터링이 중지됩니다. 설정과 기록은 유지됩니다. |

### 알림 → 알림 카테고리

모든 기기에는 알림 카테고리가 있습니다. 직접 고르지 않으면 자동으로 정해집니다: 알람으로 설정된 이벤트가 하나라도 있는 모니터링 기기는 긴급, 알림만 보내는 기기는 주의, 나머지는 일반입니다. 조건부 알림과 자동화에서 카테고리를 트리거로 사용할 수 있습니다 (예: “긴급 기기 중 하나라도 오프라인이 되면 알람 울리기”).

| 설정 | 기능 |
|---|---|
| 긴급 · 주의 · 일반 · 자동 | 자동일 때: 알람이 울리는 이벤트가 하나라도 있으면 긴급, 알림만 보내면 주의, 나머지는 일반입니다 |
| 방해 금지 시간에도 울리기 | 방해 금지 시간에도 알람이 울립니다 / 방해 금지 시간에는 알람이 알림으로 바뀝니다 |

### 알림 → 방해 금지 시간

| 설정 | 기능 |
|---|---|
| 방해 금지 시간 | 이 시간 동안에는 알람이 알림으로 바뀝니다 (중요 기기는 계속 울립니다) |
| 시작 / 종료 | 방해 금지 시간의 시작과 끝 시각. |

### 알림 → 다른 사람에게 알리기

알람이 제때 해제되지 않으면 지정한 사람들에게 Telegram 메시지가 전송되고, 해제되면 또 한 번 전송됩니다. 밤에 휴대폰이 다른 방에 있어도 집에 있는 사람이나 이웃이 알 수 있습니다. 메시지는 직접 만든 Telegram 봇이 보내며 다른 서버는 사용되지 않습니다.

| 설정 | 기능 |
|---|---|
| 1. Telegram 봇 | Telegram에서 @BotFather를 열고 /newbot을 보내 봇 이름을 정하세요. BotFather가 알려 주는 토큰을 아래에 붙여 넣으세요. |
| 2. 알릴 사람 | 각자 Telegram에서 @your_bot을(를) 열고 시작을 누르도록 요청하세요 (봇을 가족 그룹에 추가할 수도 있습니다). 그런 다음 사람 찾기를 누르세요. |
| 3. 시점 | 사람들에게 알리기 전에 알람이 울릴 수 있는 시간(또는 즉시). |
| 테스트 메시지 보내기 | 목록의 모든 사람에게 테스트 메시지를 보냅니다. |
| 끄기 | Telegram 알림을 끕니다. |

### 알림 → 스마트 알림

모든 기기를 함께 살펴보는 알림입니다: 정전, 평소와 다른 소비량, 주간 요약. Telegram으로 상태를 확인하고, 알람을 넘겨받고, 원격으로 기기를 조작할 수도 있습니다.

| 설정 | 기능 |
|---|---|
| 정전: 정전 감지 | 모니터링 중인 모든 기기가 동시에 오프라인이 되면 기기별 알림 대신 “정전” 알림 하나가 오고, 전원이 돌아오면 지속 시간과 함께 메시지가 옵니다. |

| 재택 / 외출: 재택 시 알림 완화 | 집에 있는 동안에는 긴급이 아닌 기기의 알람이 알림으로 바뀝니다 (방해 금지 시간처럼). 긴급 기기는 항상 울립니다. |
| 휴가 모드 | 외출로 간주되고, 방해 금지 시간이 꺼지며, 매일 아침 09:00에 보고서가 옵니다. 자동으로 종료됩니다. |
| 소비량: 평소와 다른 소비량 | 매일 아침 어제를 이전 2주와 비교합니다. 사용량이 훨씬 많으면 고장일 수 있고, 훨씬 적으면(거의 작동하지 않은 냉동고 등) 작동이 멈췄을 수 있습니다. |
| 전기 요금제 | 자체 가격이 없는 기기에 적용되는 기본 가격입니다. 3단계 요금제에서는 각 시간이 해당 시간대 요금으로 계산됩니다: 주간 06–17, 피크 17–22, 야간 22–06. |
| 월 예산 | 에너지 측정 기기의 예상 비용이 이 금액에 도달하면 한 달에 한 번 알려 드립니다. |
| 주간 보고서 | 매주 월요일 09:00에 지난주의 정전, 알람과 응답 시간, 연결 끊김, 소비량을 알려 줍니다. Telegram이 설정되어 있으면 그쪽으로도 전송됩니다. |
| 이번 주 보고서 보기 | 지금 바로 보여 줍니다. |
| Telegram: 명령어 및 “확인했습니다” 버튼 | 목록에 있는 사람은 /status를 보내고 울리는 알람을 넘겨받을 수 있습니다. 알람 메시지에 “확인했습니다” 버튼이 추가되며, 누르면 휴대폰의 알람이 꺼집니다. |
| 기기 켜기/끄기 허용 | /on 및 /off 명령어입니다. 목록에 있는 사람만 사용할 수 있습니다. |
| 단계별 알림 | 각 사람은 자신의 대기 시간이 지난 뒤에 메시지를 받습니다. 예를 들어 이웃은 5분 후, 친척은 15분 후, 가족 그룹은 30분 후. 누군가 “확인했습니다”를 누르면 다음 사람에게는 메시지를 보내지 않습니다. |
| 긴급 알람 시 전화 | 긴급 카테고리의 기기에서 알람이 울리면, 단계별 알림에서 정한 대기 시간이 지났을 때 이 휴대폰 회선으로 해당 사람에게 전화도 겁니다. 전화는 깨우는 역할만 합니다. 무슨 일이 일어났는지는 같은 시간에 보내는 Telegram 메시지에 있습니다 (Android는 앱이 통화에 소리를 재생하는 것을 허용하지 않습니다). 이 번호를 “SwitchGuard 알람”으로 저장해 달라고 요청하세요. 전화는 알람이 해제되거나 누군가 Telegram에서 “확인했습니다”를 누를 때까지 2분마다 최대 3번 반복됩니다. 그룹에는 전화할 수 없습니다. |
| 스마트 알림을 Telegram으로 보내기 | 정전, 평소와 다른 소비량, 예산 알림, 주간 보고서도 Telegram으로 전송됩니다. |
| 워치독 | 같은 봇을 사용하는 두 기기(예: 휴대폰과 TV 박스)가 서로를 감시합니다. 신호를 보내는 기기는 Telegram 채팅의 고정 메시지를 계속 갱신하고, 감시하는 기기는 신호가 끊기면 알람을 울리고 연락처에 메시지를 보냅니다. 그 메시지의 고정을 해제하지 마세요. |

| 이런 일이 생기면 | 꺼짐, 켜짐, 오프라인이 됨, 온라인이 됨 → 알람 / 알림 / 없음. 알람은 끌 때까지 울립니다. 알림은 일반 알림을 표시합니다. 없음은 기록에만 남깁니다. |
| 이 기기의 소리 | 전용 알람 소리, 없으면 기본 소리. |
| 알림 카테고리 | 자동일 때: 알람이 울리는 이벤트가 하나라도 있으면 긴급, 알림만 보내면 주의, 나머지는 일반입니다 |
| 에너지 | 전력, 전압, 전류. 오늘과 이번 달. 일 / 월 / 연 기록과 비용. 보고서 받기(PDF / CSV). |
| kWh당 가격 | 이 기기의 kWh당 단가 또는 기본 단가. 기본값으로 설정할 수도 있습니다. |
| 타이머 (기기에서 실행) | 타이머가 없습니다. 타이머는 휴대폰이 꺼져 있어도 기기 자체에서 실행됩니다. (eWeLink 기기: 선택한 요일의 정해진 시각에 켜기/끄기 타이머를 추가·편집.) |
| 연결 | dBm은 신호 세기입니다. 0에 가까울수록 좋습니다. -55 초과는 매우 좋음, -67까지는 좋음, -75까지는 보통, 그 아래는 약함입니다. |
| 대기 전력 소비 | 최근 7일 중 시간당 평균 전력이 가장 낮았던 값입니다. "아무것도 하지 않을 때"도 이 기기(와 여기에 연결된 모든 것)가 절대 그 아래로 내려가지 않는 전력입니다. TV, 공유기, 충전기는 대기 중에도 이 정도를 소비하는 경우가 많습니다. |
| 기기 데이터 복사 | 지원되지 않는 모델을 신고할 때 유용하도록 기기의 원시 데이터를 클립보드에 복사합니다 |

## Telegram 명령

목록에 있는 사람은 /status를 보내고 울리는 알람을 넘겨받을 수 있습니다. 알람 메시지에 “확인했습니다” 버튼이 추가되며, 누르면 휴대폰의 알람이 꺼집니다.

```
SwitchGuard 명령어:
/status – 모니터링, 알람, 기기 상태
/ack – 울리고 있는 알람 넘겨받기
/on 이름 [채널] – 기기 또는 그룹 켜기 (여러 개: /on kitchen, garden)
/off 이름 [채널] – 기기 또는 그룹 끄기
/watt [이름] – 현재 전력, 오늘 사용량, 평소 사용량
/temp – 실외 온도
/scene 이름 – 장면 실행
/home · /away – 재택 / 외출 설정

자유롭게 입력할 수도 있습니다 (영어 또는 튀르키예어): “turn off kitchen and garden”, “heater watts”, “is the pump on”.

기기 켜기/끄기와 장면은 앱에서 허용되어 있어야 합니다 (알림 → 스마트 알림).
```

영어와 터키어 명령 이름 모두 작동합니다(예: /status = /durum, /on = /ac). 명령은 선택한 채팅에서만 받습니다.

## 개인정보

- 자체 서버 없음, 분석·광고·추적 없음. 어떤 데이터도 판매하거나 공유하지 않습니다.
- 키, 토큰, 기기, 규칙, 설정, 기록(최대 2,000건)은 내 기기에만 저장됩니다.
- 앱은 연결한 클라우드(eWeLink `*.coolkit.cc` / `*.coolkit.cn`, Tuya `openapi.tuya*.com`)와, 사용하는 경우에만 Telegram, Open-Meteo(기온과 날씨, 위치는 약 100 m로 반올림), OpenStreetMap 지도 타일과만 통신합니다.
- eWeLink 비밀번호는 eWeLink 자체 페이지에서 입력하므로 앱이 보지 않습니다.
- 앱 데이터는 Android 클라우드 백업에서 제외되고, 파일 백업은 비밀번호로 보호되며, Wi-Fi 전송은 일회용 코드로 암호화되어 집 네트워크 안에서만 이루어집니다.

### 알람이 늦거나 울리지 않음

| 문제 | 해결 방법 |
|---|---|
| 백그라운드 활동이 제한되어 있습니다 | 휴대폰이 모니터링을 절전 상태로 만들 수 있어 알람이 늦거나 누락될 수 있습니다. |
| 전체 화면 알람이 허용되지 않았습니다 | 휴대폰이 잠겨 있으면 알람이 큰 화면으로 열리지 않습니다. |
| Xiaomi가 알람 화면을 차단하고 있습니다 | 휴대폰이 잠겨 있으면 알람 화면이 열리지 않습니다. 해결을 누르고 기타 권한을 연 다음 “잠금 화면에 표시”와 “백그라운드에서 실행 중일 때 새 창 열기”를 켜세요. |
| 알람 알림이 낮게 설정되어 있습니다 | “알람” 알림 카테고리가 높은 중요도로 설정되어 있지 않아 알람이 팝업으로 뜨거나 화면을 채우지 못합니다. |
| 방해 금지 모드: 완전 무음 | 이 모드에서는 알람 소리도 음소거됩니다. |
| 알람 볼륨이 매우 낮습니다 | 휴대폰의 알람 볼륨이 0이거나 0에 가까워 SwitchGuard 소리가 들리지 않을 수 있습니다. 해결을 누르면 “최대 볼륨으로 울리기”가 켜집니다. |
| 알림이 꺼져 있습니다 | 알람과 경고를 표시할 수 없습니다. |
| 이 휴대폰에 SwitchGuard가 하나 더 있습니다 | 휴대폰의 듀얼 앱(앱 복제) 기능으로 SwitchGuard의 다른 복사본이 만들어졌습니다. 두 복사본을 함께 실행하면 모든 알람이 두 번 울리고, 같은 eWeLink 계정을 사용할 경우 서로를 로그아웃시킵니다. Xiaomi 휴대폰에서는 이 복사본의 권한이 꺼진 것처럼 표시되기도 합니다. 두 번째 복사본을 제거하세요. 작은 배지가 붙은 아이콘을 길게 누르고 삭제를 탭하세요. |

### 기타 질문

**모니터링이 멈추고 로그아웃되었다고 나옵니다.**  
팁: eWeLink는 계정당 하나의 세션만 허용합니다. 휴대폰마다 별도의 eWeLink 계정을 사용하고 eWeLink 앱에서 기기를 공유하세요.

**공유받은 Tuya 기기가 보이지 않습니다.**  
공유받은 기기가 보이지 않나요? Tuya는 내 홈에 있는 기기만 표시합니다. 소유자에게 Smart Life에서 홈 구성원으로 추가해 달라고 요청하세요 (Me → Home Management → Add Member).

**Tuya 기기가 더 이상 업데이트되지 않습니다.**  
Tuya Cloud 체험 기간이 만료되어 Tuya 기기를 모니터링하지 않습니다. platform.tuya.com → Cloud → IoT Core → Extend trial period에서 연장하세요.

**변경이 늦게 도착합니다 / 즉시 업데이트를 사용할 수 없습니다.**  
이 App ID에서는 즉시 업데이트를 사용할 수 없어 주기적으로 확인합니다 (확인 간격보다 짧은 변화는 놓칠 수 있습니다)

**Google Play 버전과 GitHub 버전을 바꿔 쓸 수 있나요?**  
네, 하지만 먼저 다른 하나를 삭제하세요. 서명이 다릅니다. 삭제하기 전에 파일로 백업하고 나중에 복원하세요.

**모두를 깨우지 않고 알람을 시험하려면?**  
지금 알람을 시험해 보세요: 소리 있게 또는 무음으로, 즉시 또는 10초 후에

**소비 전력이 eWeLink / Smart Life 앱과 다른 이유는?**  
소비량은 모니터링이 켜져 있는 동안 측정한 전력 값으로 SwitchGuard가 계산하므로 기기 제조사 앱(eWeLink, Smart Life)과 약간 다를 수 있습니다.

## Windows 앱

Windows용 SwitchGuard(10 / 11)는 PC에서 같은 모니터링을 합니다. 시스템 트레이에 머물며 컴퓨터에서 전체 화면 알람을 울리고, 같은 규칙·자동화·Telegram 기능을 공유합니다. 구역, 위젯, 시계, 전화 걸기는 휴대폰 전용입니다.

### 기능

- 같은 탭: 기기, 알림, 자동화, 기록, 채팅, 설정. 채팅의 음성 명령은 Windows 음성 입력을 사용합니다.
- 트레이 아이콘: 열기, 모니터링 시작 / 중지, 알람 끄기, 종료. 창을 닫아도 모니터링은 멈추지 않습니다.
- 전체 화면 알람 창, 내장 소리(사이렌, 비프, 펄스, 차임) 또는 직접 고른 WAV / MP3.
- 대기 화면과 Windows 화면 보호기: PC가 유휴 상태가 되면 보드가 열립니다.
- 충전기에 꽂아 둔 노트북이 정전 센서 역할을 합니다.
- GitHub에서 클릭 한 번으로 업데이트, 설정과 라이선스 유지. 비밀번호로 보호된 파일로 백업(휴대폰에서는 복원 불가).

### Windows에 설치하기

1. 설치 파일(SwitchGuard-…-Kurulum.exe)을 더블클릭하세요. 관리자 권한을 요구하지 않으며 몇 초 만에 설치됩니다.
2. Windows에 "Windows의 PC 보호"(SmartScreen)가 표시되면 추가 정보 → 실행을 누르세요. 앱이 아직 서명되지 않아 경고가 나옵니다.
3. SwitchGuard는 사용자 폴더(AppData › Local › SwitchGuard)에 설치되며 바탕 화면과 시작 메뉴에 바로 가기를 추가합니다.
4. Windows에 로그인하면 트레이(시계 옆)에서 자동으로 시작됩니다. 창을 닫아도 멈추지 않습니다. 종료하려면 트레이 아이콘 → 종료를 사용하세요.
5. 설정 → 계정에서 계정을 추가하세요(Tuya와 eWeLink 단계는 아래에 있습니다).
6. 다른 컴퓨터로 옮기기: 이전 컴퓨터에서 설정 → 백업 및 전송 → 파일로 백업, 새 컴퓨터에 설치한 뒤 파일에서 복원하고 eWeLink에 다시 로그인하세요.
7. 제거하려면: Windows 설정 → 앱 → 설치된 앱 → SwitchGuard → 제거.
8. 새 버전 설치: 먼저 이전 버전을 제거한 다음(7단계) 새 설치 파일을 실행하세요. 설정, 계정, 소리는 유지됩니다. (앱의 업데이트 버튼을 누르면 자동으로 처리됩니다.)
