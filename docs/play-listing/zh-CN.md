# Play listing — zh-CN (2.26)

## Title (≤30)
SwitchGuard – 智能插座警报

## Short description (≤80)
eWeLink 或 Tuya 智能插座开关或离线时，立即发出警报。

## Full description (≤4000)
SwitchGuard 监控您 eWeLink 和 Tuya / Smart Life 账号中的智能插座和开关，一旦有变化就立即发出警报 — 冷冻柜插座被关闭、水泵停转、设备失去连接。

• 警报会一直响铃，直到您关闭，即使在静音模式下也一样 — 全屏显示，锁屏上也能弹出
• “警报可能无法送达”检查：找出会让警报静音的手机设置，一键修复
• 智能提醒：停电（所有设备同时离线，或这部手机被拔掉充电器）、异常用电、月度预算和每周报告，各只发一条提醒
• Telegram：警报未被及时关闭时，您选择的人会分级收到消息；还可用命令查看状态、接手警报、开关设备和运行场景
• 未处理时再次响铃：设备持续关闭、开启或离线期间反复提醒
• 数秒内实时更新，并带有自动备用检查
• 按设备设置规则：开启、关闭、离线和上线时，选择警报、通知或不处理
• 忽略短暂断线、免打扰时段、每台设备不同的警报声音、音量和振动
• 自动化：开关持续开启过久时发出警报，或通道在应该运行时功率下降（例如水泵堵转 — SONOFF SPM-4Relay / DUALR3）；在日出、日落或按室外温度开关设备，可限定时段和日期；开关失败会自动重试
• 循环与定时：倒计时、开启后关闭、开关重复以及分步序列，可通过按钮、指定时间或时间段启动
• 分组：将多台设备作为一台开关，可在应用、小组件和自动化中使用
• 区域：到达或离开某个地点时运行场景
• 场景以及在家 / 离家 / 度假模式
• 聊天：输入或说出“turn off the heater”之类的命令（命令支持英语或土耳其语）
• 待机屏幕：充电中的手机或平板变成时钟，显示天气、用电、最近事件和即将发生的事
• 带计量功能的设备可查看功率、电压和电量；按日、月、年查看历史及费用（单一或三段式电价）、待机功耗，并支持 PDF/CSV 报告
• 在应用中开关设备，并管理它们的 eWeLink 定时器
• 主屏幕小组件（状态、单个设备开关、整个分组、语音指令）和快速设置磁贴
• 完整的事件历史，支持 CSV 导出，另有可选的每日摘要
• 加密备份文件，便于迁移到新手机
• 支持手机、平板和 Android TV — 在电视上，警报会显示在正在播放的内容之上
• 提供 20 种语言，可在应用内切换
• 先试后用，无需账号：内置演示设备可模拟所有功能
• 无广告、无跟踪、无需我们的账号 — 您的数据保留在您的设备上
• 免费版可监控 1 台设备；一次性购买 Pro 即可监控全部设备

支持 eWeLink（SONOFF）设备 — 需要免费的 eWeLink 开发者 App ID — 以及 Tuya / Smart Life 设备 — 需要免费的 Tuya Cloud 项目。应用内指南会带您完成任一种设置。

SwitchGuard 是独立应用，与 eWeLink、CoolKit、ITEAD、Tuya 或 Telegram 无关联。
