# Play listing — zh-TW (2.26)

## Title (≤30)
SwitchGuard – 智慧插座警報

## Short description (≤80)
eWeLink 或 Tuya 智慧插座一有開關動作或離線，立即發出警報。

## Full description (≤4000)
SwitchGuard 會監看您 eWeLink 與 Tuya / Smart Life 帳號中的智慧插座和開關，一有變化就立即發出警報 —— 冷凍櫃插座被關掉、水泵停止運轉、裝置斷線，都不會漏掉。

• 警報會持續響鈴直到您解除，即使在靜音模式下也一樣 —— 全螢幕顯示，連鎖定畫面上也能看到
• 「警報可能無法送達」檢查：找出會讓警報靜音的手機設定，一鍵修正
• 智慧提醒：停電（所有裝置同時離線，或這支手機被拔掉電源）只發一則提醒，另有異常用電、每月預算和每週報告
• Telegram：警報沒有及時解除時，您選擇的人會分階段收到訊息；可用指令查看狀態、接手警報、開關裝置和執行情境
• 未處理時再次響鈴：裝置持續關閉、開啟或離線時定時提醒
• 數秒內即時更新，並有自動備援檢查
• 每個裝置獨立的規則：警報、通知或不處理 —— 可分別設定開啟、關閉、離線和上線
• 忽略短暫斷線、勿擾時段、每個裝置各自的警報音效、音量與震動
• 自動化：開關持續開啟太久時發出警報，或迴路應在運轉時功率下降（例如停轉的水泵 —— SONOFF SPM-4Relay / DUALR3）；可在日出、日落或依室外溫度開關裝置，並限定特定時段和日子；開關失敗時會自動重試
• 循環與計時器：倒數計時、先開再關、開關重複，以及逐步序列，可由按鈕、指定時間或時段啟動
• 群組：把多個裝置當成一個來開關，可從應用程式、小工具和自動化操作
• 區域：抵達或離開某個地點時執行情境
• 情境，以及在家 / 外出 / 度假模式
• 聊天：輸入或用說的下達「turn off the heater」之類的指令（指令支援英文或土耳其文）
• 待機畫面：充電中的手機或平板會變成時鐘，顯示天氣、用電量、近期事件和即將執行的項目
• 具電量計量功能的裝置可查看功率、電壓和用電量；依日、月、年查看歷史與費用（單一或三段式費率）、待機耗電，以及 PDF / CSV 報告
• 從應用程式開關裝置，並管理其 eWeLink 計時器
• 主畫面小工具（狀態、單一裝置開關、整個群組、語音指令）和快速設定圖塊
• 完整的事件記錄可匯出為 CSV，並可選擇每日摘要
• 加密備份檔案，方便換新手機
• 支援手機、平板和 Android TV —— 在電視上，警報會顯示在正在播放的內容上方
• 提供 20 種語言，可在應用程式中切換
• 不需帳號就能先試用：內建示範裝置可模擬所有功能
• 無廣告、不追蹤、不需我們的帳號 —— 您的資料只留在您的裝置上
• 免費版可監控 1 個裝置；一次性購買 Pro 即可監控所有裝置

支援 eWeLink（SONOFF）裝置 —— 需要免費的 eWeLink 開發者 App ID —— 以及 Tuya / Smart Life 裝置 —— 需要免費的 Tuya Cloud 專案。應用程式內的指南會一步步帶您完成設定。

SwitchGuard 是獨立的應用程式，與 eWeLink、CoolKit、ITEAD、Tuya 或 Telegram 無關聯。
