# Play listing — ko-KR (2.26)

## Title (≤30)
SwitchGuard – 스마트 플러그 알람

## Short description (≤80)
eWeLink 또는 Tuya 스마트 플러그가 켜지거나 꺼지거나 끊기면 즉시 알람을 울립니다.

## Full description (≤4000)
SwitchGuard는 eWeLink 및 Tuya / Smart Life 계정의 스마트 플러그와 스위치를 감시하다가 무언가 바뀌는 즉시 알람을 울립니다. 냉동고 플러그가 꺼졌을 때, 펌프가 멈췄을 때, 기기의 연결이 끊어졌을 때도 마찬가지입니다.

• 끌 때까지 계속 울리는 알람 — 무음 모드에서도, 전체 화면으로, 잠금 화면 위에서도 작동
• "알람이 전달되지 않을 수 있음" 점검: 알람을 무음으로 만들 수 있는 휴대폰 설정을 찾아 한 번의 탭으로 해결
• 스마트 알림: 정전(모든 기기가 동시에 오프라인이 되거나 이 휴대폰의 충전기가 분리된 경우), 평소와 다른 소비량, 월 예산, 주간 보고서를 각각 하나의 알림으로 제공
• Telegram: 알람이 제때 해제되지 않으면 지정한 사람들에게 단계별로 메시지 전송. 명령어로 상태 확인, 알람 넘겨받기, 기기 조작, 장면 실행 가능
• 해결될 때까지 다시 울리기: 기기가 꺼짐, 켜짐 또는 오프라인 상태로 남아 있는 동안 반복 알림
• 몇 초 이내의 실시간 업데이트와 자동 보조 확인
• 기기별 규칙: 켜짐, 꺼짐, 오프라인, 온라인에 대해 알람, 알림 또는 없음 선택
• 짧은 연결 끊김 무시, 방해 금지 시간, 기기별 알람 소리, 볼륨 및 진동
• 자동화: 스위치가 너무 오래 켜져 있거나, 켜져 있어야 할 채널의 전력이 떨어지면(예: 멈춰 선 펌프 — SONOFF SPM-4Relay / DUALR3) 알람. 일출, 일몰 또는 실외 온도에 따라, 특정 시간과 요일에만 기기 조작. 실패한 조작은 자동으로 재시도
• 사이클 및 타이머: 카운트다운, 켠 뒤 끄기, 켜기/끄기 반복, 단계별 시퀀스를 버튼, 시각 또는 시간대로 시작
• 그룹: 여러 기기를 하나처럼 앱, 위젯, 자동화에서 조작
• 구역: 특정 장소에 도착하거나 떠날 때 장면 실행
• 장면과 재택 / 외출 / 휴가 모드
• 채팅: "turn off the heater" 같은 명령을 입력하거나 말로 지시 (명령은 영어 또는 튀르키예어)
• 대기 화면: 충전 중인 휴대폰이나 태블릿을 시계, 날씨, 전력 사용량, 최근 이벤트, 예정 항목을 보여 주는 보드로 활용
• 전력 측정 기기의 전력, 전압, 에너지. 일별, 월별, 연별 기록과 비용(단일 또는 3단계 요금제), 대기 전력, PDF/CSV 보고서
• 앱에서 기기를 켜고 끄고, eWeLink 타이머 관리
• 홈 화면 위젯(상태, 기기 스위치, 그룹 전체, 음성 명령)과 빠른 설정 타일
• CSV 내보내기가 가능한 전체 이벤트 기록과 선택형 일일 요약
• 새 휴대폰으로 옮길 수 있는 암호화된 백업 파일
• 휴대폰, 태블릿, Android TV 지원 — TV에서는 재생 중인 화면 위에 알람이 표시
• 20개 언어 지원, 앱에서 전환 가능
• 계정 없이 먼저 체험: 내장 데모 기기가 모든 기능을 시뮬레이션
• 광고 없음, 추적 없음, 자체 계정 없음 — 데이터는 기기에만 저장
• 기기 1대까지 무료, 한 번의 Pro 구매로 모든 기기 모니터링

eWeLink(SONOFF) 기기에서 작동하며(무료 eWeLink 개발자 App ID 필요), Tuya / Smart Life 기기에서도 작동합니다(무료 Tuya Cloud 프로젝트 필요). 앱 내 가이드가 설정 방법을 안내합니다.

SwitchGuard는 독립 앱이며 eWeLink, CoolKit, ITEAD, Tuya, Telegram과 제휴 관계가 없습니다.
