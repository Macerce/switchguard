# Play listing — th (2.26)

## Title (≤30)
SwitchGuard – เตือนสมาร์ทปลั๊ก

## Short description (≤80)
สัญญาณเตือนทันทีเมื่อปลั๊กอัจฉริยะ eWeLink หรือ Tuya สลับสถานะหรือออฟไลน์

## Full description (≤4000)
SwitchGuard คอยดูปลั๊กอัจฉริยะและสวิตช์ในบัญชี eWeLink และ Tuya / Smart Life ของคุณ และส่งสัญญาณเตือนทันทีที่มีอะไรเปลี่ยนแปลง — ปลั๊กตู้แช่แข็งถูกปิด ปั๊มหยุดทำงาน หรืออุปกรณ์ขาดการเชื่อมต่อ

• สัญญาณเตือนที่ดังต่อเนื่องจนกว่าคุณจะปิด แม้ในโหมดเงียบ — เต็มหน้าจอ แม้บนหน้าจอล็อก
• ตรวจสอบ "สัญญาณเตือนอาจไปไม่ถึงคุณ": ค้นหาการตั้งค่าโทรศัพท์ที่ทำให้สัญญาณเตือนเงียบและแก้ไขให้ในแตะเดียว
• การแจ้งเตือนอัจฉริยะ: แจ้งครั้งเดียวเมื่อไฟดับ (อุปกรณ์ทั้งหมดออฟไลน์พร้อมกัน หรือถอดปลั๊กโทรศัพท์เครื่องนี้) การใช้ไฟผิดปกติ งบประมาณรายเดือน และรายงานรายสัปดาห์
• Telegram: หากไม่ปิดสัญญาณเตือนทันเวลา คนที่คุณเลือกจะได้รับข้อความเป็นขั้นตอน ตรวจสอบสถานะ รับช่วงสัญญาณเตือน สลับอุปกรณ์ และเรียกใช้ฉากด้วยคำสั่ง
• เตือนซ้ำหากยังไม่แก้ไข: เตือนต่อเนื่องขณะอุปกรณ์ยังปิด เปิด หรือออฟไลน์อยู่
• อัปเดตสดภายในไม่กี่วินาที พร้อมการตรวจสอบสำรองอัตโนมัติ
• กฎรายอุปกรณ์: สัญญาณเตือน การแจ้งเตือน หรือไม่ทำอะไร — สำหรับเปิด ปิด ออฟไลน์ และออนไลน์
• ข้ามการหลุดการเชื่อมต่อชั่วครู่ ช่วงเวลาเงียบ เสียงเตือนที่ต่างกันในแต่ละอุปกรณ์ ระดับเสียงและการสั่น
• ระบบอัตโนมัติ: แจ้งเตือนเมื่อสวิตช์เปิดค้างนานเกินไป หรือเมื่อกำลังไฟของช่องลดลงขณะที่ควรทำงานอยู่ (เช่น ปั๊มที่ติดขัด — SONOFF SPM-4Relay / DUALR3) สลับอุปกรณ์ตอนพระอาทิตย์ขึ้น ตก หรือตามอุณหภูมิภายนอก เฉพาะบางชั่วโมงและบางวัน สลับที่ล้มเหลวจะลองใหม่อัตโนมัติ
• วงจรและตัวจับเวลา: นับถอยหลัง เปิดแล้วปิด เปิด/ปิดซ้ำ และลำดับทีละขั้น เริ่มด้วยปุ่ม เวลา หรือช่วงเวลา
• กลุ่ม: สลับหลายอุปกรณ์พร้อมกันเป็นหนึ่งเดียว จากแอป วิดเจ็ต และระบบอัตโนมัติ
• โซน: เรียกใช้ฉากเมื่อคุณมาถึงหรือออกจากสถานที่
• ฉาก และโหมดอยู่บ้าน / ไม่อยู่ / พักร้อน
• แชท: พิมพ์หรือพูดคำสั่ง เช่น "ปิดเครื่องทำความร้อน" (คำสั่งเป็นภาษาอังกฤษหรือภาษาตุรกี)
• หน้าจอสแตนด์บาย: โทรศัพท์หรือแท็บเล็ตที่กำลังชาร์จกลายเป็นนาฬิกาพร้อมสภาพอากาศ การใช้ไฟ เหตุการณ์ล่าสุด และสิ่งที่กำลังจะเกิดขึ้น
• กำลังไฟ แรงดัน และพลังงานบนอุปกรณ์ที่วัดกำลังไฟได้ ประวัติรายวัน รายเดือน และรายปีพร้อมค่าใช้จ่าย (อัตราเดียวหรือสามอัตรา) การใช้ไฟขณะสแตนด์บาย และรายงาน PDF/CSV
• เปิดและปิดอุปกรณ์จากแอป และจัดการตัวตั้งเวลา eWeLink ของอุปกรณ์
• วิดเจ็ตบนหน้าจอหลัก (สถานะ สวิตช์ของอุปกรณ์ ทั้งกลุ่ม คำสั่งเสียง) และไทล์การตั้งค่าด่วน
• ประวัติเหตุการณ์ครบถ้วนพร้อมส่งออก CSV และสรุปรายวันแบบเลือกได้
• ไฟล์สำรองข้อมูลที่เข้ารหัสสำหรับย้ายไปโทรศัพท์เครื่องใหม่
• โทรศัพท์ แท็บเล็ต และ Android TV — บนทีวี สัญญาณเตือนจะขึ้นทับสิ่งที่กำลังเล่นอยู่
• มีให้เลือก 20 ภาษา สลับได้ในแอป
• ลองก่อนโดยไม่ต้องมีบัญชี: อุปกรณ์สาธิตในตัวจำลองทุกฟีเจอร์
• ไม่มีโฆษณา ไม่ติดตาม ไม่ต้องมีบัญชีของเรา — ข้อมูลของคุณอยู่ในอุปกรณ์ของคุณ
• ฟรีสำหรับ 1 อุปกรณ์ ซื้อ Pro ครั้งเดียวเพื่อตรวจสอบอุปกรณ์ทั้งหมดของคุณ

ใช้ได้กับอุปกรณ์ eWeLink (SONOFF) — ต้องมี App ID นักพัฒนา eWeLink ฟรี — และอุปกรณ์ Tuya / Smart Life — ต้องมีโปรเจกต์ Tuya Cloud ฟรี คู่มือในแอปจะพาคุณทำทีละขั้น

SwitchGuard เป็นแอปอิสระและไม่มีส่วนเกี่ยวข้องกับ eWeLink, CoolKit, ITEAD, Tuya หรือ Telegram
