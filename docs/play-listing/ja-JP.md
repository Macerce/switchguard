# Play listing — ja-JP (2.26)

## Title (≤30)
SwitchGuard – スマートプラグ警報

## Short description (≤80)
eWeLink・Tuyaのスマートプラグの切替やオフラインを検知し、すぐにアラームでお知らせ。

## Full description (≤4000)
SwitchGuardは、eWeLinkとTuya / Smart Lifeのアカウントにあるスマートプラグやスイッチを見守り、変化があった瞬間にアラームを鳴らします。冷凍庫のプラグがオフになった、ポンプが止まった、デバイスの接続が切れた、といった異常をすぐに知らせます。

• 止めるまで鳴り続けるアラーム — マナーモード中でも、ロック画面でも全画面で表示
• 「アラームが届かない可能性」チェック: アラームを消音してしまうスマートフォンの設定を見つけ、ワンタップで修正
• スマートアラート: 停電（全デバイスが同時にオフライン、またはこのスマートフォンの充電器が抜けた）、いつもと違う消費量、月間予算、週次レポートを1件にまとめて通知
• Telegram: アラームが時間内に止められないと、選んだ人に段階的にメッセージを送信。状況の確認、アラームの引き継ぎ、デバイスの操作、シーンの実行をコマンドで行えます
• 解消されるまで再度鳴らす: デバイスがオフ、オン、オフラインのままの間、リマインダーを送信
• 数秒以内のリアルタイム更新と、自動バックアップ確認
• デバイスごとのルール: オン、オフ、オフライン、オンラインそれぞれに、アラーム、通知、なしを設定
• 短時間の切断を無視、サイレント時間、デバイスごとに異なるアラーム音、音量とバイブレーション
• オートメーション: スイッチがオンのまま長時間続いたとき、またはチャンネルの電力が稼働中に低下したとき（例: 停止したポンプ — SONOFF SPM-4Relay / DUALR3）にアラーム。日の出、日の入り、外気温に応じてデバイスを操作、時間帯と曜日の指定も可能。失敗した操作は自動で再試行
• サイクルとタイマー: カウントダウン、オンからオフ、オン・オフの繰り返し、ステップ式シーケンスを、ボタン、時刻、時間帯で開始
• グループ: 複数のデバイスを1つとして、アプリ、ウィジェット、オートメーションから操作
• ゾーン: ある場所への到着や出発でシーンを実行
• シーンと、在宅 / 外出 / バケーションモード
• チャット: 「turn off the heater」のようなコマンドを入力または音声で指示（コマンドは英語またはトルコ語）
• スタンバイ画面: 充電中のスマートフォンやタブレットが、天気、電力使用量、最近のイベント、今後の予定を表示する時計に
• 電力計測対応デバイスの電力、電圧、消費電力量。日・月・年ごとの履歴とコスト（単一または3段階料金）、待機時消費電力、PDF/CSVレポート
• アプリからデバイスをオン・オフし、eWeLinkのタイマーも管理
• ホーム画面ウィジェット（ステータス、デバイスのスイッチ、グループ全体、音声コマンド）とクイック設定タイル
• CSVエクスポート付きの完全なイベント履歴と、オプションの日次サマリー
• 新しいスマートフォンへの移行に使える、暗号化されたバックアップファイル
• スマートフォン、タブレット、Android TVに対応 — テレビでは再生中の画面の上にアラームが表示されます
• 20言語に対応し、アプリ内で切り替え可能
• まずはアカウントなしでお試し: 内蔵のデモデバイスがすべての機能をシミュレートします
• 広告なし、トラッキングなし、当社のアカウントも不要 — データはお使いのデバイスに残ります
• 1台まで無料。買い切りのProで、すべてのデバイスを監視

eWeLink（SONOFF）デバイスで利用できます（無料のeWeLink開発者App IDが必要）。Tuya / Smart Lifeデバイスでも利用できます（無料のTuya Cloudプロジェクトが必要）。アプリ内ガイドがどちらの手順も案内します。

SwitchGuardは独立したアプリであり、eWeLink、CoolKit、ITEAD、Tuya、Telegramとは提携していません。
