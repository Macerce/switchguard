# SwitchGuard

SwitchGuard 监控你自己的 **eWeLink / SONOFF** 和 **Tuya / Smart Life** 账户中的智能插座和开关，一旦有变化就立即发出真正的警报——水泵停了、冰柜插座被关了、设备断开了连接。它可在 Android 手机、平板、Android TV 和 Wear OS 手表上运行，另外还有 Windows 应用。

## 下载

### Android (手机、平板、电视)
- **Google Play**: https://play.google.com/store/apps/details?id=com.macerce.switchguard
- **APK**: [最新 Android 版本](https://github.com/Macerce/switchguard/releases/latest) — 下载 `SwitchGuard-x.y.z.apk` 并在手机上打开。如果已从 Google Play 安装了 SwitchGuard，请先卸载（签名不同）。GitHub 版本会在有新版时提醒你。

### Windows 10 / 11
- **安装程序**: [Windows 版本](https://github.com/Macerce/switchguard/releases?q=Windows&expanded=true) — 从最新版本下载 `SwitchGuard-x.y.z-Kurulum.exe` 并运行。应用会自行查找新版本并一键更新；设置会保留。

### 免费版与 Pro
- 免费：全部功能，可监控 1 台设备。演示设备让你无需硬件即可试用所有功能。
- Android：Pro 是 Google Play 上的一次性购买（无订阅），可监控所有设备；随 Google 账户转移到新手机。
- Windows：Pro 许可证密钥（设置 → 套餐卡片）可监控所有设备。获取密钥请联系 **switchguardapp@gmail.com**

## 系统要求

- Android 8.0+（API 26）；手表应用需要 Wear OS
- eWeLink：一个免费的 eWeLink 开发者应用（App ID + App Secret）——应用内指南会一步步带你完成。eWeLink 每个账户和 App ID 只允许一个会话，因此每台手机、平板、电视或电脑都需要自己的 eWeLink 账户，并把设备共享给它 ([dev.ewelink.cc](https://dev.ewelink.cc))
- Tuya / Smart Life：你自己的免费 Tuya Cloud 项目的 Access ID 和 Access Secret，并已关联你的 Smart Life / Tuya 应用账户 ([platform.tuya.com](https://platform.tuya.com))
- Windows 应用需要 Windows 10 / 11（64 位）

## 功能

### 监控与警报

- 通过 eWeLink WebSocket 和 Tuya 消息服务实时更新，并以 HTTP 重新同步和定期检查作为备用。
- 警报会一直响到你关闭为止——即使在静音模式下——并在锁屏上全屏打开；每台设备都可以有自己的铃声。
- 按设备设置规则：设备关闭、打开、离线或恢复在线时，发出警报、通知或不做任何事。
- 条件提醒：设备持续开启或关闭一段时间，或功率高于 / 低于某个阈值时响铃（例如水泵功率低于 50 W）。
- 忽略短暂断线；监控本身停止时（无网络 / 云）发出警告；eWeLink 会话丢失时大声提醒（例如同一账户在另一台手机上登录）。
- 就绪卡片会显示并修复可能阻止警报的手机设置（电池限制、全屏权限、勿扰模式、闹钟音量……）。

### 设备

- 智能家居风格的磁贴，带快速开关按钮；多通道设备每个通道一个按钮；实时状态和功率。
- 设备页面：规则、专属警报铃声、提醒类别、能耗历史和费用、eWeLink 定时器、Wi-Fi 信号与断线诊断、待机功耗和最近事件。
- **排列设备**: 星标 = 置顶 · 箭头 = 移动 · 卡片大小 = 小或大 · 标签 = 分类。长按卡片可返回此处。

### 提醒

- 设备提醒和条件提醒集中在一处，可按提醒类别筛选（关键 / 重要 / 普通）。
- 提醒设置：警报铃声和音量、免打扰时段、提醒类别、Telegram（“通知其他人”）和智能提醒——见下方 *全部设置*。
- 智能提醒：停电时只发一条提醒、异常用电、月度预算、每周报告、度假模式。

### 自动化

- **规则** — 自动操作：*如果* 发生了某事，*那么* 执行某个操作，可选延迟。
- 触发条件: 开启, 关闭, 持续开启达, 持续关闭达, 离线, 恢复在线, 功率高于, 功率低于, 日出时, 日落时, 室外温度升高到高于, 室外温度降低到低于, 到达时, 离开时.
- 操作: 开启, 关闭, 发出警报, 发送通知, 运行场景, 开始循环, 停止循环.
- **仅当**: 仅在这些时段, 并且仅当另一台设备…, 仅在家 / 离家时.
- **场景** — 选择场景运行时每台设备要执行的操作。保持“跳过”的设备不会被改动。
- **分组** — 选择分组中的设备。分组会像设备一样显示在“设备”界面：其按钮可同时开启或关闭所有设备，也可用于自动化。
- **循环与定时** — 倒计时, 开启后关闭, 开关循环, 逐个开启, 自定义步骤. 可通过按钮启动、在所选日期的固定时间启动或在某个时间段内运行；可选随机变化（营造有人在家的效果）和“手动更改时停止”。
- 自动化在监控开启期间于此手机上运行。如需在手机关机时也能生效的定时计划，请使用设备页面上的定时器。

### 能耗

- 按日 / 月 / 年查看：总量、估算费用、平均和峰值功率、用电最多的小时/日/月以及要点摘要。
- 单一电价或三段电价（白天 / 高峰 / 夜间），可按设备设置电价或使用默认电价。
- 待机功耗（设备从不低于的功率）及其每月费用。
- 能耗报告可导出为 PDF（打印或分享）或 CSV（Excel、Google 表格）。
- 用电量由 SwitchGuard 根据监控开启期间读取的功率计算，因此可能与设备厂商的应用（eWeLink、Smart Life）略有差异。

### 历史

- 每个事件都带有日期和时间，以及由谁或什么触发（应用、自动化）；可按设备筛选。
- 导出为 CSV（最近 24 小时、7 天、30 天或全部）以及清除历史。

### 聊天

- 你好。你可以通过输入文字来管理设备：开关设备、查询状态、功率或室外温度。点按麦克风可改为语音输入（“Turn off kitchen”）；回复会朗读出来。下方有现成的模板；点按即可发送，长按可编辑。指令需使用英文或土耳其文。
- 自由文本命令可离线使用，支持英语和土耳其语；麦克风使用手机的语音识别，回复可朗读出来。
- 模板：一键发送的消息，也可以每天在固定时间或发生某事时自动运行。

### 待机屏幕

- 适用于充电中手机或平板的全屏看板：时钟、天气、关键状态、实时功率、最近活动以及接下来的计划。它也会显示在锁屏上方。
- 打开 Android 设置：在“屏保”下选择 SwitchGuard，并设为充电时启动。这样充电时看板会取代锁屏。

### 小部件、快捷设置磁贴、快捷方式

- **SwitchGuard** — 显示监控是否正在运行以及正在响铃的警报
- **SwitchGuard 开关** — 点按即可开关一台设备或一个通道。也可以设置为 在家 / 离家 或运行某个场景。
- **SwitchGuard 分组** — 大磁贴：单独开关分组中的每台设备
- **SwitchGuard 语音指令** — 一个磁贴：点按、说出指令（“Turn off kitchen”），即可执行
- **快捷设置磁贴**——显示监控状态，并可启动或停止监控（需先解锁手机）；警报响起时会打开应用。
- **应用快捷方式**——长按应用图标即可使用 在家 / 离家 和你的场景。

### 在家 / 离家

- **在家 / 离家** — 标有“仅离家时”的规则不会运行。离家时请切换为“离家”（也可通过小组件、手表或 Telegram 的 /away）。
- **度假模式** — 视为离家，免打扰时段关闭，每天早上 09:00 收到一份报告。到期后自动结束。
- **区域** — 在地图上选择一个区域；当您的手机进入或离开该区域时运行自动化（例如到家时打开庭院灯，离开时关闭所有设备）。地图图片从 OpenStreetMap 下载；您的位置仅在此手机上使用。

### Wear OS

- SwitchGuard 手表应用显示警报（在手腕上关闭）、设备（开关）、场景以及 在家 / 离家；它与手机应用相连。

### Android TV

- 在 Android TV 上用遥控器操作；警报会显示在正在播放的任何内容之上（“在其他应用上层显示警报”）。
- “从手机输入”：电视显示二维码；你在手机上输入密钥，密钥经家庭 Wi-Fi 加密发送到电视。
- “从其他设备接收”：通过 Wi-Fi 从手机复制 Tuya 密钥、规则和设置。

### 多台设备

手机、平板、Android TV 和电脑：**每台设备都需要自己的 eWeLink 账户（已批准开发者功能）以及该账户自己的 API 密钥（App ID / Secret）**——eWeLink 每个账户只允许一台设备登录。请在 eWeLink 应用中把设备共享给额外的账户。Tuya 密钥可以在多台设备上使用。Pro 只需购买一次，可在同一 Google 账户的所有 Android 设备上使用。详情： [English](docs/guide/ewelink.en.md#using-several-devices-phone-tablet-android-tv) · [Türkçe](docs/guide/ewelink.tr.md#birden-fazla-cihazda-kullanım-telefon-tablet-android-tv)

### 演示与 Pro

- **演示设备** — 用于体验所有功能的虚拟设备。这些操作相当于设备本身发生了变化（有人操作了开关、断电或 Wi-Fi 中断），因此您的规则会生效，警报也可能响铃。使用上方按钮进行的开关操作视为您本人所为，不会触发警报。
- 免费版可监控 1 台设备。Pro 版可监控您的所有设备，并包含全部功能。一次性付费，无需订阅。与您的 Google 账号绑定，因此换新手机时可随您迁移。

| 警报声音 | 通用警报铃声。每台设备都可以有自己的铃声（设备页面）。 |
| 警报音量 | SwitchGuard 自己的警报音量。 |
| 振动 | 警报响起时振动。 |
| 以最大音量响铃 | 警报响铃期间将手机的警报音量调到最大并暂停音乐；关闭警报后恢复 |
| 未处理时再次响铃 | 关闭警报后，只要设备仍处于触发警报的状态（仍关闭、仍开启或离线），就会按此间隔再次响铃。设备恢复正常后停止。 |
| 通知其他人 | Telegram 设置（见下文）。 |
| 测试警报 | 立即试用警报：有声或静音，立即或 10 秒后 |

### 提醒 → 提醒类别

每台设备都有一个提醒类别。除非您手动选择，否则会自动设定：已监控且有任何事件设为“警报”的设备为“关键”，只发送通知的为“重要”，其余为“普通”。条件提醒和自动化可以将类别用作触发条件（例如“任何关键设备离线时发出警报”）。

| 设置 | 作用 |
|---|---|
| 关键 · 重要 · 普通 · 自动 | 自动时：只要有事件触发警报即为“关键”，事件只发通知则为“重要” |
| 免打扰时段也响铃 | 免打扰时段警报也会响铃 / 免打扰时段警报会变为通知 |

### 提醒 → 免打扰时段

| 设置 | 作用 |
|---|---|
| 免打扰时段 | 在这些时段内，警报会变为通知（关键设备仍会响铃） |
| 开始时间 / 结束时间 | 免打扰时段的开始和结束时间。 |

被设置为在免打扰时段也响铃的提醒类别中的设备（默认为“关键”）仍会响铃。

### 提醒 → 通知其他人

如果警报未被及时关闭，您选择的人会收到一条 Telegram 消息，警报关闭后还会再收到一条。即使夜里手机放在另一个房间，家里的其他人或邻居也能知道。消息由您自己创建的 Telegram 机器人发送，不涉及其他服务器。

| 设置 | 作用 |
|---|---|
| 1. Telegram 机器人 | 在 Telegram 中打开 @BotFather，发送 /newbot 并为您的机器人命名。将 BotFather 给您的令牌粘贴到下方。 |
| 2. 要通知的人 | 请每位联系人在 Telegram 中打开 @your_bot 并点按 Start（也可以将机器人添加到家庭群）。然后点按“查找联系人”。 |
| 3. 通知时机 | 警报响多久后通知他人（或立即通知）。 |
| 发送测试消息 | 向列表中的所有人发送测试消息。 |
| 关闭 | 关闭 Telegram 通知。 |

### 提醒 → 智能提醒

综合查看所有设备的提醒：停电、异常用电和每周摘要。借助 Telegram，您还可以远程查看状态、接手警报和开关设备。

| 设置 | 作用 |
|---|---|
| 停电: 检测停电 | 如果所有受监控设备同时离线，您只会收到一条“停电”提醒，而不是每台设备一条；供电恢复时会收到包含持续时间的消息。 |
| 将充电器用作电力传感器 | 如果这部手机/平板一直插电放在现场，拔掉充电器一分钟即视为停电；断网时同样有效。消息通过移动数据经 Telegram 发出。 |
| 在家 / 离家: 在家时降低提醒强度 | 在家时，非关键设备的警报会变为通知（类似免打扰时段）。关键设备始终会响铃。 |
| 度假模式 | 视为离家，免打扰时段关闭，每天早上 09:00 收到一份报告。到期后自动结束。 |
| 用电量: 异常用电 | 每天早上将昨天与前两周比较。用电量明显偏高可能意味着故障；明显偏低（例如冷冻柜几乎没运转）可能意味着它已停止工作。 |
| 电价方案 | 未单独设置电价的设备所用的默认电价。采用三段式电价时，每个小时按所属时段计价：白天 06–17，高峰 17–22，夜间 22–06。 |
| 月度预算 | 当带电量计量的设备的预估电费达到此金额时，每月通知您一次。 |
| 每周报告 | 每周一 09:00：上周的停电、警报与响应时间、断线和用电量。如已设置，也会发送到 Telegram。 |
| 显示本周报告 | 立即显示。 |
| Telegram: 命令和“收到”按钮 | 名单中的人可以发送 /status 并接手正在响铃的警报。警报消息带有“收到”按钮：按下后手机会静音。 |
| 允许开关设备 | /on 和 /off 命令。仅名单中的人可以使用。 |
| 分级通知 | 每个人在各自的等待时间后收到消息。例如邻居 5 分钟后，亲属 15 分钟后，家庭群 30 分钟后。如果有人点按“收到”，则不再通知后面的人。 |
| 严重警报时拨打电话 | 当“关键”类别中的设备触发警报，且分级提醒中某人的等待时间已到时，也会用这部手机的号码给此人打电话。电话只用于叫醒对方：具体发生了什么在同时发出的 Telegram 消息里（Android 不允许应用向通话中播放声音）。请让对方将此号码保存为“SwitchGuard 警报”。电话每 2 分钟重复一次，最多 3 次，直到警报被关闭或有人在 Telegram 中点按“收到”。无法给群组打电话。 |
| 将智能提醒发送到 Telegram | 停电、异常用电、预算提醒和每周报告也会发送到 Telegram。 |
| 看门狗 | 使用同一个机器人的两台设备互相监视（例如手机和电视盒子）。发送方设备会持续更新 Telegram 聊天中的一条置顶消息；监视方设备在其停止时会发出警报并给您的联系人发消息。请不要取消置顶该消息。 |

### 设备页面（点按某台设备）

| 设置 | 作用 |
|---|---|
| 监控此设备 | 将按下方规则记录变化并提醒 |
| 发生以下情况时 | 关闭, 开启, 离线, 上线 → 警报 / 通知 / 无. 警报会一直响铃，直到您关闭。通知显示普通通知。无仅在历史记录中记录事件。 |
| 此设备的声音 | 设备专属警报铃声；否则使用通用铃声。 |
| 提醒类别 | 自动时：只要有事件触发警报即为“关键”，事件只发通知则为“重要” |
| 能耗 | 功率、电压、电流；今天和本月；按日 / 月 / 年的历史及费用；生成报告（PDF / CSV）。 |
| 每千瓦时电价 | 此设备的每 kWh 电价或默认电价；也可设为默认值。 |
| 定时器（设备端） | 没有定时器。定时器在设备本身运行，即使手机关机也能生效。（eWeLink 设备：在所选日期的固定时间添加或编辑开/关定时器。） |
| 连接 | dBm 表示信号强度：越接近 0 越好。高于 -55 为极好，到 -67 为良好，到 -75 为一般，更低则较弱。 |
| 待机功耗 | 最近 7 天内最低的小时平均值：即使在“什么都不做”时，此设备（及其所接的任何设备）的功率也从不低于该值。电视、路由器和充电器在待机时往往有这样的功耗。 |
| 复制设备数据 | 将设备的原始数据复制到剪贴板，便于反馈不受支持的型号 |

## Telegram 命令

名单中的人可以发送 /status 并接手正在响铃的警报。警报消息带有“收到”按钮：按下后手机会静音。

```
SwitchGuard 命令：
/status – 监控、警报和设备状态
/ack – 接手正在响铃的警报
/on 名称 [通道] – 开启设备或分组（可多个：/on 厨房, 花园）
/off 名称 [通道] – 关闭设备或分组
/watt [名称] – 当前功率、今日用电和平时功率
/temp – 室外温度
/scene 名称 – 运行场景
/home · /away – 设为在家 / 离家

也可以直接用自然语言：“关闭厨房和花园”、“暖风机功率”、“水泵开着吗”。

需要在应用中允许通过 Telegram 开关设备和运行场景（提醒 → 智能提醒）。
```

英语和土耳其语命令名都可以使用（例如 /status = /durum，/on = /ac）。只接受来自你所选聊天的命令。

## 隐私

## 故障排除与常见问题

### 警报延迟或不响

| 问题 | 解决方法 |
|---|---|
| 后台活动受限 | 手机可能会让监控进入休眠；警报可能延迟或漏掉。 |
| 不允许全屏警报 | 手机锁定时，警报无法打开其大屏界面。 |
| 小米阻止了警报界面 | 手机锁定时，警报界面无法打开。点按“修复”，打开“其他权限”，开启“锁屏显示”和“后台弹出界面”。 |
| 警报通知被调低了 | “警报”通知类别未设为高优先级，因此警报不会弹出或占满屏幕。 |
| 勿扰模式：完全静音 | 在此模式下，连警报声音也会被静音。 |
| 警报音量非常低 | 手机的警报音量为零或接近零，您可能听不到 SwitchGuard。点按“修复”将开启“以最大音量响铃”。 |
| 通知已关闭 | 无法显示警报和提醒。 |
| 此手机上有第二个 SwitchGuard | 另一个 SwitchGuard 副本是通过手机的“应用分身”功能创建的。两个副本同时运行时，每个警报都会响两次；如果使用同一个 eWeLink 账号，它们还会互相将对方登出；在小米手机上，此副本的权限也可能显示为已关闭。请移除第二个副本：长按其图标（带有小角标的那个），然后点按“卸载”。 |

### 会停止后台应用的手机厂商

| 手机 | 解决方法 |
|---|---|
| Xiaomi | 用于在重启或更新后恢复监控。点按并为 SwitchGuard 开启自启动。 |
| Samsung | 三星可能会让应用进入休眠。请在“电池”中选择“不受限制”，并将 SwitchGuard 添加到“永不休眠的应用”（电池 → 后台使用限制）。 |
| Huawei / Honor | 在“应用启动管理”中，将 SwitchGuard 设为“手动管理”，并开启自启动、关联启动和后台活动。 |
| OPPO / realme / OnePlus | 为 SwitchGuard 开启自动启动，然后在其电池设置中允许后台活动。 |
| vivo / iQOO | 允许 SwitchGuard 在后台启动，并允许高后台耗电。 |
| Tecno / Infinix | 在手机管家中为 SwitchGuard 开启自启动，使监控在重启和清理后仍能运行。 |
| ASUS | 在自启动管理器中允许 SwitchGuard，使监控在重启后恢复运行。 |

### 其他问题

**监控停止了，并提示我已退出登录。**  
提示：eWeLink 每个账号只允许一个登录会话。请为每部手机使用各自的 eWeLink 账号，并在 eWeLink 应用中共享设备。

**别人共享给我的 Tuya 设备没有出现。**  
缺少别人共享给您的设备？Tuya 只列出您家庭中的设备。请让所有者在 Smart Life 中将您添加为家庭成员（我 → 家庭管理 → 添加成员）。

**Tuya 设备不再更新。**  
Tuya Cloud 试用已到期，因此不会监控 Tuya 设备。请在 platform.tuya.com → Cloud → IoT Core → Extend trial period 中续期。

**变化到达得很慢 / 无法使用即时更新。**  
此 App ID 不支持即时更新，改用定期检查（短于检查间隔的变化可能漏掉）

**可以在 Google Play 版和 GitHub 版之间切换吗？**  
可以，但要先卸载另一个版本：两者签名不同。卸载前先备份到文件，之后再恢复。

**如何在不吵醒所有人的情况下测试警报？**  
立即试用警报：有声或静音，立即或 10 秒后

**为什么用电量和 eWeLink / Smart Life 应用不同？**  
用电量由 SwitchGuard 根据监控开启期间读取的功率计算，因此可能与设备厂商的应用（eWeLink、Smart Life）略有差异。

## Windows 应用

SwitchGuard for Windows（10 / 11）在电脑上进行同样的监控：常驻系统托盘，在电脑上全屏响起警报，并共享相同的规则、自动化和 Telegram 功能。区域、小部件、手表和电话呼叫仅限手机。

### 功能

- 相同的标签页：设备, 提醒, 自动化, 历史, 聊天, 设置；聊天中的语音命令使用 Windows 语音输入。
- 托盘图标：打开、开始 / 停止监控、关闭警报、退出；关闭窗口不会停止监控。
- 全屏警报窗口，内置铃声（警笛, 蜂鸣, 脉冲, 钟声）或你自己的 WAV / MP3。
- 待机屏幕和 Windows 屏幕保护程序：电脑空闲时打开看板。
- 插着充电器的笔记本电脑可作为停电传感器。
- 从 GitHub 一键更新；设置和许可证保留。备份到受密码保护的文件（无法在手机上恢复）。

### 仅限 Windows 的设置

| 设置 | 作用 |
|---|---|
| Windows | 让 SwitchGuard 在这台电脑上不间断地守护。只要有一项关闭，重启后或电脑睡眠期间就可能漏掉警报。 |
| 随 Windows 启动 | 登录 Windows 时在托盘中打开 |
| 保持电脑唤醒 | 监控期间电脑不会进入睡眠 |
| 用作 Windows 屏幕保护程序 | 电脑空闲时会打开待机屏幕；移动鼠标或按任意键即可关闭 |
| 等待 | 电脑需要空闲多久才会打开待机屏幕 |
| Windows 屏幕保护程序设置 | 例如“在恢复时显示登录屏幕” |
| 打开待机屏幕 | 全屏；按 Esc 关闭，点击可“打开应用”。打开期间屏幕保持常亮。 |
| 语言和外观: 主题 | 浅色、深色或跟随 Windows。 |
| 语言 | 选择应用、通知和警报使用的语言。 |
| 在这台电脑上接收 Tuya 实时更新 | 关闭：每 5 分钟检查一次 Tuya 设备 |
| 这台电脑改用电池供电时视为停电 | 适用于在家插着电源的笔记本电脑：如果用电池运行一分钟，即视为停电，即使没有网络（连接恢复后会发送 Telegram 消息）。 |
| 这台电脑与设备使用同一电源 | 只要它使用市电运行，就不存在停电，因此掉线的设备会立即报告，而不是最多等待 90 秒。 |
| 从文件加载… | 为警报或通知使用你自己的 WAV 或 MP3（前 60 秒，最大 20 MB）。 |
| 备份到文件… | 所有设置、账号密钥和声音保存在一个受密码保护的文件中 |
| 激活 Pro | 没有许可证时，应用可监控 1 台设备。输入许可证密钥即可监控你的所有设备。 |

### 在 Windows 上安装

1. 双击安装文件（SwitchGuard-…-Kurulum.exe）。它不需要管理员权限，几秒钟即可装好。
2. 如果 Windows 提示“Windows 已保护你的电脑”（SmartScreen），点更多信息 → 仍要运行。应用尚未签名，所以会有此警告。
3. SwitchGuard 安装在你的用户文件夹（AppData › Local › SwitchGuard）中，并在桌面和开始菜单添加快捷方式。
4. 登录 Windows 时它会自动在托盘（时钟旁）启动。关闭窗口不会停止它；要退出，请使用托盘图标 → 退出。
5. 在设置 → 账号中添加你的账号（Tuya 和 eWeLink 的步骤见下方）。
6. 迁移到另一台电脑：在旧电脑上，设置 → 备份与迁移 → 备份到文件；在新电脑上安装后，从文件恢复，然后重新登录 eWeLink。
7. 卸载：Windows 设置 → 应用 → 已安装的应用 → SwitchGuard → 卸载。
8. 安装新版本：先卸载旧版本（第 7 步），再运行新的安装文件。你的设置、账号和声音会保留。
