# SwitchGuard

SwitchGuard เฝ้าดูปลั๊กและสวิตช์อัจฉริยะในบัญชี **eWeLink / SONOFF** และ **Tuya / Smart Life** ของคุณเอง และส่งเสียงเตือนจริงทันทีที่มีอะไรเปลี่ยนไป ไม่ว่าจะเป็นปั๊มที่หยุดทำงาน ปลั๊กตู้แช่ที่ถูกปิด หรืออุปกรณ์ที่ขาดการเชื่อมต่อ ใช้งานได้บนโทรศัพท์และแท็บเล็ต Android, Android TV และนาฬิกา Wear OS และยังมีแอปสำหรับ Windows ด้วย

## ดาวน์โหลด

### Android (โทรศัพท์ แท็บเล็ต ทีวี)
- **Google Play**: https://play.google.com/store/apps/details?id=com.macerce.switchguard
- **APK**: [เวอร์ชัน Android ล่าสุด](https://github.com/Macerce/switchguard/releases/latest) — ดาวน์โหลด `SwitchGuard-x.y.z.apk` แล้วเปิดบนโทรศัพท์ ถ้าติดตั้ง SwitchGuard จาก Google Play อยู่แล้ว ให้ถอนการติดตั้งก่อน (ลายเซ็นต่างกัน) เวอร์ชัน GitHub จะแจ้งเมื่อมีเวอร์ชันใหม่

### Windows 10 / 11
- **ตัวติดตั้ง**: [เวอร์ชันสำหรับ Windows](https://github.com/Macerce/switchguard/releases?q=Windows&expanded=true) — ดาวน์โหลด `SwitchGuard-x.y.z-Kurulum.exe` จากเวอร์ชันล่าสุดแล้วเรียกใช้ แอปค้นหาเวอร์ชันใหม่เองและอัปเดตได้ในคลิกเดียว การตั้งค่ายังอยู่ครบ

### ฟรีและ Pro
- Android: ฟรีทั้งหมด — ทุกฟีเจอร์ เฝ้าดูอุปกรณ์ได้ทุกเครื่อง ไม่มีการซื้อ อุปกรณ์สาธิตช่วยให้ลองทุกอย่างได้โดยไม่ต้องมีฮาร์ดแวร์
- Windows ฟรี: ทุกฟีเจอร์ สำหรับอุปกรณ์ที่เฝ้าดู 1 เครื่อง
- Windows: คีย์ใบอนุญาต Pro (การตั้งค่า → การ์ดแผน) เฝ้าดูอุปกรณ์ทั้งหมด ติดต่อขอคีย์ได้ที่ **switchguardapp@gmail.com**

## ข้อกำหนด

- Android 8.0 ขึ้นไป (API 26); Wear OS สำหรับแอปนาฬิกา
- eWeLink: แอปนักพัฒนา eWeLink ฟรี (App ID + App Secret) — คู่มือในแอปจะพาทำทีละขั้น eWeLink อนุญาตเพียงหนึ่งเซสชันต่อบัญชีและ App ID ดังนั้นโทรศัพท์ แท็บเล็ต ทีวี หรือ PC แต่ละเครื่องต้องมีบัญชี eWeLink ของตัวเองที่แชร์อุปกรณ์ไว้ ([dev.ewelink.cc](https://dev.ewelink.cc))
- Tuya / Smart Life: Access ID และ Access Secret ของโปรเจกต์ Tuya Cloud ฟรีของคุณเอง ที่เชื่อมกับบัญชีแอป Smart Life / Tuya ([platform.tuya.com](https://platform.tuya.com))
- Windows 10 / 11 (64 บิต) สำหรับแอป Windows

## ฟีเจอร์

### การเฝ้าดูและสัญญาณเตือน

- อัปเดตสดผ่าน WebSocket ของ eWeLink และบริการข้อความของ Tuya พร้อมการซิงก์ใหม่ทาง HTTP และการตรวจเป็นระยะเป็นทางสำรอง
- สัญญาณเตือนดังจนกว่าคุณจะปิด แม้อยู่ในโหมดเงียบ และเปิดเต็มจอบนหน้าจอล็อก อุปกรณ์แต่ละเครื่องมีเสียงของตัวเองได้
- กฎรายอุปกรณ์: สัญญาณเตือน การแจ้งเตือน หรือไม่ทำอะไร เมื่ออุปกรณ์ปิด เปิด ออฟไลน์ หรือกลับมาออนไลน์
- การแจ้งเตือนแบบมีเงื่อนไข: ดังเมื่ออุปกรณ์เปิดหรือปิดค้างไว้ระยะหนึ่ง หรือกำลังไฟสูงกว่า / ต่ำกว่าเกณฑ์ (เช่น ปั๊มกินไฟต่ำกว่า 50 W)
- ไม่สนใจการหลุดสั้นๆ, เตือนเมื่อการเฝ้าดูเองหยุดทำงาน (ไม่มีอินเทอร์เน็ต / คลาวด์), เตือนเสียงดังเมื่อเซสชัน eWeLink หลุด (เช่น บัญชีเดียวกันเข้าสู่ระบบบนโทรศัพท์อีกเครื่อง)
- การ์ดความพร้อมแสดงและแก้การตั้งค่าโทรศัพท์ที่อาจขัดขวางสัญญาณเตือน (การจำกัดแบตเตอรี่ สิทธิ์เต็มจอ ห้ามรบกวน ระดับเสียงนาฬิกาปลุก…)

### อุปกรณ์

- ไทล์สไตล์บ้านอัจฉริยะพร้อมปุ่มเปิด/ปิดด่วน ปุ่มแยกต่อช่องสำหรับอุปกรณ์หลายช่อง สถานะและกำลังไฟแบบสด
- หน้าอุปกรณ์: กฎ เสียงเตือนของตัวเอง หมวดการแจ้งเตือน ประวัติพลังงานและค่าใช้จ่าย ตัวตั้งเวลา eWeLink สัญญาณ Wi-Fi และการวินิจฉัยการหลุด การใช้ไฟขณะสแตนด์บาย และเหตุการณ์ล่าสุด
- **จัดเรียงอุปกรณ์**: ดาว = ปักไว้ด้านบน · ลูกศร = ย้าย · ขนาดการ์ด = เล็กหรือใหญ่ · แท็ก = หมวดหมู่ กดการ์ดค้างไว้เพื่อกลับมาที่นี่

### การแจ้งเตือน

- การแจ้งเตือนอุปกรณ์และการแจ้งเตือนแบบมีเงื่อนไขในที่เดียว กรองตามหมวดการแจ้งเตือนได้ (สำคัญมาก / สำคัญ / ปกติ)
- การตั้งค่าการแจ้งเตือน: เสียงและระดับเสียงสัญญาณเตือน ช่วงเวลาเงียบ หมวดการแจ้งเตือน Telegram ("แจ้งคนอื่น") และการแจ้งเตือนอัจฉริยะ — ดู *การตั้งค่าทั้งหมด* ด้านล่าง
- การแจ้งเตือนอัจฉริยะ: แจ้งครั้งเดียวเมื่อไฟดับ การใช้ไฟผิดปกติ งบประมาณรายเดือน รายงานประจำสัปดาห์ โหมดพักร้อน

### ระบบอัตโนมัติ

- **กฎ** — การทำงานอัตโนมัติ: *ถ้า* มีบางอย่างเกิดขึ้น *ก็* ทำบางอย่าง พร้อมหน่วงเวลาได้
- ตัวกระตุ้น: เปิด, ปิด, เปิดค้างนาน, ปิดค้างนาน, ออฟไลน์, กลับมาออนไลน์, กำลังไฟเกิน, กำลังไฟตกต่ำกว่า, ตอนพระอาทิตย์ขึ้น, ตอนพระอาทิตย์ตก, เมื่ออุณหภูมิภายนอกสูงกว่า, เมื่ออุณหภูมิภายนอกต่ำกว่า, เมื่อมาถึง, เมื่อออกไป.
- การกระทำ: เปิด, ปิด, ส่งเสียงเตือน, ส่งการแจ้งเตือน, เรียกใช้ฉาก, เริ่มวงจร, หยุดวงจร.
- **เฉพาะเมื่อ**: เฉพาะในช่วงชั่วโมงเหล่านี้, และเฉพาะเมื่ออุปกรณ์อื่น…, เฉพาะเมื่ออยู่บ้าน / ไม่อยู่.
- **ฉาก** — เลือกสิ่งที่จะเกิดกับแต่ละอุปกรณ์เมื่อฉากทำงาน อุปกรณ์ที่ตั้งเป็น “ข้าม” จะไม่ถูกแตะต้อง
- **กลุ่ม** — เลือกอุปกรณ์ในกลุ่ม กลุ่มจะแสดงในหน้าอุปกรณ์เหมือนอุปกรณ์ ปุ่มของกลุ่มจะเปิดหรือปิดทั้งหมดพร้อมกัน และใช้ในระบบอัตโนมัติได้
- **วงจรและตัวจับเวลา** — นับถอยหลัง, เปิดแล้วปิด, วงจรเปิด/ปิด, ทีละเครื่อง, ขั้นตอนกำหนดเอง. เริ่มด้วยปุ่ม ตามเวลาที่กำหนดในวันที่เลือก หรือในช่วงเวลาหนึ่ง เลือกได้ว่าจะสุ่มเวลาเล็กน้อย (ดูเหมือนมีคนอยู่บ้าน) และ "หยุดเมื่อมีการเปลี่ยนด้วยมือ"
- ระบบอัตโนมัติทำงานบนโทรศัพท์เครื่องนี้ขณะเปิดการตรวจสอบ สำหรับตารางเวลาที่ต้องทำงานแม้โทรศัพท์ปิดอยู่ ให้ใช้ตัวตั้งเวลาในหน้าอุปกรณ์

### พลังงาน

- มุมมองรายวัน / รายเดือน / รายปี พร้อมยอดรวม ค่าใช้จ่ายโดยประมาณ กำลังไฟเฉลี่ยและสูงสุด ชั่วโมง/วัน/เดือนที่ใช้มากที่สุด และสรุปจุดเด่น
- อัตราเดียวหรือสามช่วง (กลางวัน / ช่วงพีค / กลางคืน) ราคาต่ออุปกรณ์หรือราคาเริ่มต้น
- การใช้ไฟขณะสแตนด์บาย (กำลังไฟที่อุปกรณ์ไม่เคยต่ำกว่า) และค่าใช้จ่ายต่อเดือน
- รายงานพลังงานเป็น PDF (พิมพ์หรือแชร์) หรือ CSV (Excel, Google ชีต)
- SwitchGuard คำนวณการใช้ไฟจากค่ากำลังไฟที่อ่านขณะเปิดการตรวจสอบ จึงอาจต่างจากแอปของผู้ผลิตอุปกรณ์ (eWeLink, Smart Life) เล็กน้อย

### ประวัติ

- ทุกเหตุการณ์พร้อมวันที่และเวลา และใครหรืออะไรเป็นผู้เปลี่ยน (แอป ระบบอัตโนมัติ) กรองตามอุปกรณ์ได้
- ส่งออกเป็น CSV (24 ชั่วโมง 7 วัน 30 วันล่าสุด หรือทั้งหมด) และล้างประวัติ

### แชท

- สวัสดี คุณจัดการอุปกรณ์ได้ด้วยการเขียน: เปิดหรือปิด ถามสถานะ การใช้ไฟ หรืออุณหภูมิภายนอก แตะไมโครโฟนเพื่อพูดแทน (“Turn off kitchen”) คำตอบจะถูกอ่านออกเสียง เทมเพลตสำเร็จรูปอยู่ด้านล่าง แตะเพื่อส่ง กดค้างเพื่อแก้ไข
- คำสั่งพิมพ์อิสระทำงานได้โดยไม่ต้องใช้อินเทอร์เน็ตและเข้าใจภาษาอังกฤษกับภาษาตุรกี ไมโครโฟนใช้ระบบรู้จำเสียงของโทรศัพท์ และอ่านคำตอบออกเสียงได้
- เทมเพลต: ข้อความแตะครั้งเดียว ซึ่งตั้งให้ทำงานเองทุกวันตามเวลาหรือเมื่อมีเหตุการณ์ได้ด้วย

### หน้าจอสแตนด์บาย

- บอร์ดเต็มหน้าจอสำหรับโทรศัพท์หรือแท็บเล็ตที่กำลังชาร์จ: นาฬิกา สภาพอากาศ สถานะสำคัญ กำลังไฟสด กิจกรรมล่าสุด และสิ่งที่จะทำงานถัดไป แสดงทับหน้าจอล็อกด้วย
- เปิดการตั้งค่า Android: เลือก SwitchGuard ใต้ภาพพักหน้าจอ และตั้งให้เริ่มขณะชาร์จ บอร์ดจะแทนหน้าจอล็อกขณะอยู่บนที่ชาร์จ

### วิดเจ็ต ไทล์การตั้งค่าด่วน ทางลัด

- **SwitchGuard** — แสดงว่ากำลังตรวจสอบอยู่หรือไม่ และสัญญาณเตือนที่กำลังดัง
- **สวิตช์ SwitchGuard** — เปิดและปิดอุปกรณ์หรือช่องเดียวด้วยการแตะ ตั้งเป็น อยู่บ้าน / ไม่อยู่ หรือให้เรียกใช้ฉากก็ได้
- **กลุ่ม SwitchGuard** — ไทล์ใหญ่: เปิดหรือปิดแต่ละอุปกรณ์ในกลุ่มแยกกัน
- **คำสั่งเสียง SwitchGuard** — ไทล์เดียว: แตะ พูด (“ปิดห้องครัว”) แล้วสั่งงาน
- **ไทล์การตั้งค่าด่วน** — แสดงสถานะการเฝ้าดู และเริ่มหรือหยุดการเฝ้าดู (ต้องปลดล็อกโทรศัพท์ก่อน) ระหว่างที่สัญญาณเตือนดังจะเปิดแอป
- **ทางลัดแอป** — กดค้างที่ไอคอนแอปเพื่อเลือก อยู่บ้าน / ไม่อยู่ และฉากของคุณ

### อยู่บ้าน / ไม่อยู่

- **อยู่บ้าน / ไม่อยู่** — กฎที่ทำเครื่องหมาย “เฉพาะเมื่อไม่อยู่” จะไม่ทำงาน สลับเป็นไม่อยู่เมื่อคุณออกไป (ทำได้จากวิดเจ็ต นาฬิกา หรือ Telegram /away)
- **โหมดพักร้อน** — คุณจะนับว่าไม่อยู่ ช่วงเวลาเงียบปิด และมีรายงานมาทุกเช้าเวลา 09:00 สิ้นสุดเองอัตโนมัติ
- **โซน** — เลือกพื้นที่บนแผนที่ ระบบอัตโนมัติจะทำงานเมื่อโทรศัพท์ของคุณเข้าหรือออกจากพื้นที่นั้น (เช่น เปิดไฟสวนเมื่อถึงบ้าน ปิดทุกอย่างเมื่อออกไป) ภาพแผนที่ดาวน์โหลดจาก OpenStreetMap ตำแหน่งของคุณใช้บนโทรศัพท์เครื่องนี้เท่านั้น

### Wear OS

- แอปนาฬิกา SwitchGuard แสดงสัญญาณเตือน (ปิดได้จากข้อมือ) อุปกรณ์ (เปิด/ปิด) ฉาก และ อยู่บ้าน / ไม่อยู่ โดยเชื่อมต่อกับแอปบนโทรศัพท์

### Android TV

- ทำงานบน Android TV ด้วยรีโมต สัญญาณเตือนจะแสดงทับทุกอย่างที่กำลังเล่นอยู่ ("แสดงสัญญาณเตือนทับแอปอื่น")
- "กรอกจากโทรศัพท์": ทีวีแสดงคิวอาร์โค้ด คุณพิมพ์คีย์บนโทรศัพท์ แล้วคีย์จะถูกเข้ารหัสส่งไปยังทีวีผ่าน Wi-Fi ในบ้าน
- "รับจากอุปกรณ์อื่น": คัดลอกคีย์ Tuya กฎ และการตั้งค่าจากโทรศัพท์ผ่าน Wi-Fi

### หลายอุปกรณ์

โทรศัพท์ แท็บเล็ต Android TV และ PC: **แต่ละเครื่องต้องมีบัญชี eWeLink ของตัวเองที่ได้รับอนุมัติฟีเจอร์นักพัฒนา และคีย์ API ของบัญชีนั้นเอง (App ID / Secret)** — eWeLink อนุญาตอุปกรณ์ที่ลงชื่อเข้าใช้เพียงหนึ่งเครื่องต่อบัญชี แชร์อุปกรณ์ของคุณให้บัญชีเพิ่มเติมจากแอป eWeLink คีย์ Tuya ใช้บนหลายอุปกรณ์ได้ รายละเอียด: [English](docs/guide/ewelink.en.md#using-several-devices-phone-tablet-android-tv) · [Türkçe](docs/guide/ewelink.tr.md#birden-fazla-cihazda-kullanım-telefon-tablet-android-tv)

### สาธิต

- **อุปกรณ์สาธิต** — อุปกรณ์เสมือนสำหรับลองทุกฟีเจอร์ ปุ่มเหล่านี้ทำเหมือนมีเหตุการณ์เกิดที่ตัวอุปกรณ์เอง (มีคนสลับ ไฟดับ หรือ Wi-Fi ขาด) กฎของคุณจึงมีผลและสัญญาณเตือนดังได้ การสลับด้วยปุ่มด้านบนนับว่าเป็นคุณ และจะไม่ส่งเสียงเตือน

ทุกอุปกรณ์มีหมวดการแจ้งเตือน หากคุณไม่เลือก ระบบจะตั้งให้อัตโนมัติ: อุปกรณ์ที่ตรวจสอบและมีเหตุการณ์ใดตั้งเป็นสัญญาณเตือนคือสำคัญมาก อุปกรณ์ที่ส่งเพียงการแจ้งเตือนคือสำคัญ ที่เหลือคือปกติ การแจ้งเตือนตามเงื่อนไขและระบบอัตโนมัติใช้หมวดเป็นตัวกระตุ้นได้ (เช่น “ส่งเสียงเตือนเมื่ออุปกรณ์สำคัญมากเครื่องใดออฟไลน์”)

| การตั้งค่า | ทำอะไร |
|---|---|
| สำคัญมาก · สำคัญ · ปกติ · อัตโนมัติ | เมื่อเป็นอัตโนมัติ: สำคัญมากหากมีเหตุการณ์ใดส่งเสียงเตือน สำคัญหากเหตุการณ์เพียงแจ้งเตือน |
| ดังในช่วงเวลาเงียบด้วย | สัญญาณเตือนดังในช่วงเวลาเงียบด้วย / ในช่วงเวลาเงียบ สัญญาณเตือนจะกลายเป็นการแจ้งเตือน |

### การแจ้งเตือน → ช่วงเวลาเงียบ

| การตั้งค่า | ทำอะไร |
|---|---|
| ช่วงเวลาเงียบ | ในช่วงเวลานี้ สัญญาณเตือนจะกลายเป็นการแจ้งเตือน (อุปกรณ์สำคัญยังคงดัง) |

อุปกรณ์ในหมวดการแจ้งเตือนที่ตั้งให้ดังในช่วงเวลาเงียบ (ค่าเริ่มต้นคือสำคัญ) ยังคงดัง

### การแจ้งเตือน → แจ้งคนอื่น

หากไม่ปิดสัญญาณเตือนทันเวลา คนที่คุณเลือกจะได้รับข้อความ Telegram และอีกข้อความเมื่อปิดแล้ว แม้โทรศัพท์ของคุณอยู่อีกห้องตอนกลางคืน คนในบ้านหรือเพื่อนบ้านก็จะรู้ ข้อความส่งโดยบอต Telegram ที่คุณสร้างเอง ไม่ผ่านเซิร์ฟเวอร์อื่นใด

| 3. เมื่อไร | สัญญาณเตือนดังได้นานเท่าใดก่อนแจ้งคนอื่น (หรือทันที) |

## คำสั่ง Telegram

คนในรายชื่อของคุณส่ง /status และรับช่วงสัญญาณเตือนที่กำลังดังได้ ข้อความสัญญาณเตือนจะมีปุ่ม “รับทราบ” กดแล้วโทรศัพท์จะเงียบ

```
คำสั่ง SwitchGuard:
/status – การตรวจสอบ สัญญาณเตือน และอุปกรณ์
/ack – รับช่วงสัญญาณเตือนที่กำลังดัง
/on ชื่อ [ช่อง] – เปิดอุปกรณ์หรือกลุ่ม (หลายรายการ: /on kitchen, garden)
/off ชื่อ [ช่อง] – ปิดอุปกรณ์หรือกลุ่ม
/watt [ชื่อ] – กำลังไฟตอนนี้ วันนี้ และที่ใช้ตามปกติ
/temp – อุณหภูมิภายนอก
/scene ชื่อ – เรียกใช้ฉาก
/home · /away – ตั้งเป็นอยู่บ้าน / ไม่อยู่

คุณเขียนอิสระได้ด้วย: “turn off kitchen and garden”, “heater watts”, “is the pump on”

ต้องอนุญาตการเปิดและปิดอุปกรณ์และฉากในแอปก่อน (การแจ้งเตือน → การแจ้งเตือนอัจฉริยะ)
```

ใช้ได้ทั้งชื่อคำสั่งภาษาอังกฤษและภาษาตุรกี (เช่น /status = /durum, /on = /ac) รับคำสั่งเฉพาะจากแชตที่คุณเลือกเท่านั้น

## ความเป็นส่วนตัว

- ไม่มีเซิร์ฟเวอร์ของตัวเอง ไม่มีการวิเคราะห์ โฆษณา หรือการติดตาม ไม่มีการขายหรือแชร์ข้อมูล
- คีย์ โทเค็น อุปกรณ์ กฎ การตั้งค่า และประวัติ (สูงสุด 2,000 เหตุการณ์) เก็บไว้บนอุปกรณ์ของคุณเท่านั้น
- แอปสื่อสารเฉพาะกับคลาวด์ที่คุณเชื่อมต่อ (eWeLink `*.coolkit.cc` / `*.coolkit.cn`, Tuya `openapi.tuya*.com`) และเฉพาะเมื่อคุณใช้เท่านั้น กับ Telegram, Open-Meteo (อุณหภูมิและสภาพอากาศ ตำแหน่งปัดเศษราว 100 ม.) และไทล์แผนที่ OpenStreetMap
- รหัสผ่าน eWeLink พิมพ์บนหน้าของ eWeLink เอง แอปไม่เคยเห็น
- ข้อมูลแอปไม่รวมอยู่ในการสำรองข้อมูลบนคลาวด์ของ Android การสำรองเป็นไฟล์มีรหัสผ่านป้องกัน การโอนผ่าน Wi-Fi เข้ารหัสด้วยรหัสใช้ครั้งเดียวและอยู่ในเครือข่ายบ้านของคุณ

## แอป Windows

SwitchGuard สำหรับ Windows (10 / 11) เฝ้าดูแบบเดียวกันบน PC: อยู่ในถาดระบบ ส่งสัญญาณเตือนเต็มจอบนคอมพิวเตอร์ และใช้กฎ ระบบอัตโนมัติ และฟีเจอร์ Telegram ร่วมกัน ส่วนโซน วิดเจ็ต นาฬิกา และการโทรมีเฉพาะบนโทรศัพท์

### ฟีเจอร์

- แท็บเดียวกัน: อุปกรณ์, การแจ้งเตือน, ระบบอัตโนมัติ, ประวัติ, แชท, การตั้งค่า คำสั่งเสียงในแชตใช้การพิมพ์ด้วยเสียงของ Windows
- ไอคอนในถาด: เปิด เริ่ม / หยุดการเฝ้าดู ปิดสัญญาณเตือน ออก การปิดหน้าต่างไม่ทำให้การเฝ้าดูหยุด
- หน้าต่างสัญญาณเตือนเต็มจอ เสียงในตัว (ไซเรน, บี๊บ, ชีพจร, ระฆัง) หรือไฟล์ WAV / MP3 ของคุณเอง
- หน้าจอสแตนด์บายและโปรแกรมรักษาหน้าจอของ Windows: กระดานเปิดเมื่อ PC ไม่ได้ใช้งาน
- แล็ปท็อปที่เสียบชาร์จไว้ใช้เป็นเซนเซอร์ไฟดับได้
- อัปเดตจาก GitHub ในคลิกเดียว การตั้งค่าและใบอนุญาตยังอยู่ สำรองเป็นไฟล์ที่มีรหัสผ่าน (กู้คืนบนโทรศัพท์ไม่ได้)

### การติดตั้งบน Windows

1. ดับเบิลคลิกไฟล์ติดตั้ง (SwitchGuard-…-Kurulum.exe) ไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ และติดตั้งเสร็จในไม่กี่วินาที
2. ถ้า Windows แจ้งว่า "Windows ปกป้องพีซีของคุณ" (SmartScreen) ให้กด ข้อมูลเพิ่มเติม → เรียกใช้ต่อไป แอปยังไม่ได้ลงนาม จึงมีคำเตือน
3. SwitchGuard ติดตั้งในโฟลเดอร์ผู้ใช้ของคุณ (AppData › Local › SwitchGuard) และเพิ่มทางลัดบนเดสก์ท็อปและเมนูเริ่ม
4. แอปเริ่มเองในถาดระบบ (ข้างนาฬิกา) เมื่อคุณลงชื่อเข้าใช้ Windows การปิดหน้าต่างไม่ได้หยุดแอป หากต้องการออก ใช้ไอคอนในถาด → ออก
5. เพิ่มบัญชีใน การตั้งค่า → บัญชี (ขั้นตอนของ Tuya และ eWeLink อยู่ด้านล่าง)
6. ย้ายไปคอมพิวเตอร์เครื่องอื่น: บนเครื่องเก่า การตั้งค่า → สำรองข้อมูลและโอนย้าย → สำรองเป็นไฟล์ ติดตั้งบนเครื่องใหม่ กู้คืนจากไฟล์ แล้วลงชื่อเข้าใช้ eWeLink อีกครั้ง
7. หากต้องการถอนการติดตั้ง: การตั้งค่า Windows → แอป → แอปที่ติดตั้ง → SwitchGuard → ถอนการติดตั้ง
8. ติดตั้งเวอร์ชันใหม่: ถอนการติดตั้งเวอร์ชันเก่าก่อน (ขั้นตอนที่ 7) แล้วเรียกใช้ไฟล์ติดตั้งใหม่ การตั้งค่า บัญชี และเสียงของคุณจะยังอยู่ (ปุ่มอัปเดตในแอปจะทำขั้นตอนนี้ให้เอง)

SwitchGuard เป็นแบบ **source-available** (เปิดให้ดูซอร์สโค้ด) ไม่ใช่โอเพนซอร์ส ซอร์สโค้ด: [PolyForm Noncommercial 1.0.0](LICENSE) ใช้ส่วนตัวและใช้แบบไม่แสวงหากำไรอื่นๆ ได้ฟรี ห้ามขายโค้ดหรือใช้เชิงพาณิชย์ เวอร์ชันจนถึง 2.8.3 เผยแพร่ภายใต้ GPL-3.0

บิลด์ทางการ (Google Play, [Releases](https://github.com/Macerce/switchguard/releases)) ใครก็ใช้ได้ รวมถึงธุรกิจ เวอร์ชันที่ดัดแปลงห้ามใช้ชื่อหรือโลโก้ SwitchGuard ติดต่อขอสัญญาอนุญาตเชิงพาณิชย์: **switchguardapp@gmail.com**

ไม่มีส่วนเกี่ยวข้อง ไม่ได้รับการรับรอง หรือสนับสนุนโดย eWeLink, CoolKit หรือ ITEAD Sonoff และ eWeLink เป็นเครื่องหมายการค้าของเจ้าของที่เกี่ยวข้อง และไม่มีส่วนเกี่ยวข้องกับ Tuya เช่นกัน
