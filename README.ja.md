# SwitchGuard

SwitchGuard は、あなた自身の **eWeLink / SONOFF** と **Tuya / Smart Life** アカウントにあるスマートプラグやスイッチを見守り、何かが変わった瞬間に本物のアラームを鳴らします。止まったポンプ、電源が切れた冷凍庫、接続が切れたデバイスなど。Android スマートフォン・タブレット、Android TV、Wear OS ウォッチで動作し、Windows 版アプリもあります。

## ダウンロード

### Android (スマートフォン、タブレット、テレビ)
- **Google Play**: https://play.google.com/store/apps/details?id=com.macerce.switchguard
- **APK**: [最新の Android リリース](https://github.com/Macerce/switchguard/releases/latest) — `SwitchGuard-x.y.z.apk` をダウンロードしてスマートフォンで開きます。Google Play から SwitchGuard をインストール済みの場合は、先にアンインストールしてください（署名が異なります）。GitHub 版は新しいバージョンが出ると知らせてくれます。

### Windows 10 / 11
- **インストーラー**: [Windows リリース](https://github.com/Macerce/switchguard/releases?q=Windows&expanded=true) — 最新のリリースから `SwitchGuard-x.y.z-Kurulum.exe` をダウンロードして実行します。アプリは新しいバージョンを自分で探し、ワンクリックで更新します。設定は保持されます。

### 無料版と Pro
- Android：完全無料 — すべての機能、すべてのデバイスを監視、購入なし。デモデバイスを使えば、機器がなくてもすべて試せます。
- Windows 無料版：すべての機能を、監視デバイス 1 台まで利用できます。
- Windows：Pro ライセンスキー（設定 → プランカード）ですべてのデバイスを監視します。キーのお問い合わせ先： **switchguardapp@gmail.com**

## 動作要件

- Android 8.0 以上（API 26）。ウォッチアプリには Wear OS
- eWeLink：無料の eWeLink 開発者アプリ（App ID + App Secret）。アプリ内ガイドが手順を案内します。eWeLink はアカウントと App ID ごとに 1 セッションしか許可しないため、スマートフォン・タブレット・テレビ・PC ごとに、デバイスを共有した専用の eWeLink アカウントが必要です ([dev.ewelink.cc](https://dev.ewelink.cc))
- Tuya / Smart Life：Smart Life / Tuya アプリのアカウントと連携した、あなた自身の無料 Tuya Cloud プロジェクトの Access ID と Access Secret ([platform.tuya.com](https://platform.tuya.com))
- Windows 版アプリには Windows 10 / 11（64 ビット）

## 機能

### 監視とアラーム

- eWeLink の WebSocket と Tuya のメッセージサービスによるリアルタイム更新。予備として HTTP 再同期と定期チェック。
- アラームは止めるまで鳴り続け（マナーモードでも）、ロック画面の上に全画面で表示されます。デバイスごとに音を変えられます。
- デバイスごとのルール：オフ、オン、オフライン、オンライン復帰のときに、アラーム・通知・何もしない、を選べます。
- 条件付きアラート：デバイスが一定時間オンまたはオフのままのとき、または電力がしきい値を上回る / 下回るときに鳴らします（例：50 W 未満のポンプ）。
- 短い切断を無視、監視そのものが止まったとき（インターネット / クラウドなし）の警告、eWeLink セッションが失われたときの大きな警告（例：同じアカウントが別のスマートフォンでログイン）。
- 準備状況カードが、アラームを妨げるおそれのある端末設定（バッテリー制限、全画面の許可、サイレントモード、アラーム音量…）を表示して修正します。

### デバイス

- スマートホーム風のタイル：クイック電源ボタン、マルチチャンネル機器ではチャンネルごとのボタン、リアルタイムの状態と電力。
- デバイスページ：ルール、専用アラーム音、アラートカテゴリ、電力履歴と費用、eWeLink のタイマー、Wi-Fi 信号と切断の診断、待機電力、最近のイベント。
- **デバイスを並べ替え**: 星 = 先頭に固定 · 矢印 = 移動 · カードサイズ = 小または大 · タグ = カテゴリ。カードを長押しするとここに戻ります。

### アラート

- デバイスアラートと条件付きアラートを 1 か所に。アラートカテゴリ（重要 / やや重要 / 通常）で絞り込めます。
- アラート設定：アラーム音と音量、サイレント時間、アラートカテゴリ、Telegram（「他の人にも知らせる」）、スマートアラート。下の *すべての設定* を参照。
- スマートアラート：停電時は 1 件のアラートだけ、異常な消費、月間予算、週次レポート、バケーションモード。

### オートメーション

- **ルール** — 自動アクション：*もし* 何かが起きたら、*そのとき* 何かを実行（遅延の指定も可）。
- トリガー: がオンになったとき, がオフになったとき, がオンのまま次の時間経過したとき, がオフのまま次の時間経過したとき, がオフラインになったとき, がオンラインに復帰したとき, の電力が次の値を超えたとき, の電力が次の値を下回ったとき, 日の出のとき, 日の入りのとき, 外気温が次の値を上回ったとき, 外気温が次の値を下回ったとき, 到着したとき, 出発したとき.
- アクション: オンにする, オフにする, アラームを鳴らす, 通知を送る, シーンを実行, サイクルを開始, サイクルを停止.
- **次の場合のみ**: この時間帯のみ, かつ、別のデバイスが次の場合のみ…, 在宅 / 外出中のみ.
- **シーン** — シーンの実行時に各デバイスをどうするかを選びます。「スキップ」のままのデバイスは操作されません。
- **グループ** — グループに含めるデバイスを選びます。グループはデバイス画面にデバイスと同じように表示され、そのボタンでまとめてオン・オフでき、オートメーションでも使えます。
- **サイクルとタイマー** — カウントダウン, オンにしてからオフ, オン・オフの繰り返し, 1台ずつ, カスタムステップ. ボタンで開始、選んだ曜日の決まった時刻に開始、または時間帯の間だけ実行。オプションでランダムなゆらぎ（在宅に見せる）と「手動で変更したら停止」。
- オートメーションは監視がオンの間、このスマートフォン上で動作します。スマートフォンの電源が切れていても動作させたいスケジュールには、デバイスページのタイマーを使用してください。

### エネルギー

- 日 / 月 / 年ごとの表示：合計、推定コスト、平均・ピーク電力、最も多く使った時間/日/月、ハイライトのまとめ。
- 単一料金または 3 段階料金（昼 / ピーク / 夜）、デバイスごとの単価または既定の単価。
- 待機電力（デバイスが決して下回らない電力）とその月額。
- 電力レポートを PDF（印刷・共有用）または CSV（Excel、Google スプレッドシート）で出力。
- 消費量は、監視中に取得した電力値からSwitchGuardが計算するため、メーカーのアプリ（eWeLink、Smart Life）の値とわずかに異なる場合があります。

### 履歴

- すべてのイベントを日時と、誰または何が変更したか（アプリ、オートメーション）付きで記録。デバイスで絞り込み可能。
- CSV へのエクスポート（直近 24 時間、7 日、30 日、すべて）と履歴の消去。

### チャット

- こんにちは。文章を入力してデバイスを管理できます: オン・オフ、状況、消費電力、外気温の確認など（コマンドは英語またはトルコ語）。マイクをタップすると声で伝えられ（“Turn off kitchen”）、返信は読み上げられます。用意されたテンプレートが下にあります。タップで送信、長押しで編集できます。
- 自由文のコマンドはオフラインで動作し、英語とトルコ語を理解します。マイクは端末の音声認識を使い、返答は読み上げることができます。
- テンプレート：ワンタップで送れるメッセージ。毎日決まった時刻や何かが起きたときに自動実行することもできます。

### スタンバイ画面

- 充電中のスマートフォンやタブレット向けの全画面ボードです: 時計、天気、重要なステータス、リアルタイムの電力、最近のアクティビティ、次に実行される予定を表示します。ロック画面の上にも表示されます。
- Androidの設定が開きます。スクリーンセーバーでSwitchGuardを選び、充電中に開始するよう設定してください。充電器に接続中は、ボードがロック画面の代わりに表示されます。

### ウィジェット、クイック設定タイル、ショートカット

- **SwitchGuard** — 監視の実行状況と鳴動中のアラームを表示します
- **SwitchGuardスイッチ** — タップで1台のデバイスまたはチャンネルをオン・オフします。在宅 / 外出 の切り替えやシーンの実行にも設定できます。
- **SwitchGuardグループ** — 大きなタイル: グループ内の各デバイスを個別にオン・オフします
- **SwitchGuard音声コマンド** — 1つのタイル: タップして「キッチンをオフ」と話すと実行されます
- **クイック設定タイル**：監視の状態を表示し、監視を開始・停止します（先にロック解除が必要）。アラーム中はアプリを開きます。
- **アプリのショートカット**：アプリアイコンを長押しすると 在宅 / 外出 とシーンを選べます。

### 在宅 / 外出

- **在宅 / 外出** — 「外出中のみ」に設定したルールは実行されません。外出するときは外出に切り替えてください（ウィジェット、ウォッチ、Telegramの /away からも可能です）。
- **バケーションモード** — 外出扱いになり、サイレント時間はオフになり、毎朝9:00にレポートが届きます。自動的に終了します。
- **ゾーン** — 地図上でエリアを選ぶと、スマートフォンがそのエリアに入ったとき、または出たときにオートメーションが実行されます（例: 帰宅したら庭の照明をつける、外出したらすべて消す）。地図画像はOpenStreetMapからダウンロードされ、位置情報はこのスマートフォン内でのみ使用されます。

### Wear OS

- SwitchGuard のウォッチアプリは、アラーム（手首から停止）、デバイス（オン/オフ）、シーン、在宅 / 外出 を表示し、スマートフォンのアプリと接続します。

### Android TV

- Android TV でリモコン操作に対応。アラームは再生中のどんな画面の上にも表示されます（「他のアプリの上にアラームを表示」）。
- 「スマートフォンから入力」：テレビに QR コードが表示され、スマートフォンでキーを入力すると、自宅の Wi-Fi 経由で暗号化されてテレビに届きます。
- 「別のデバイスから受信」：Tuya のキー、ルール、設定を Wi-Fi でスマートフォンからコピーします。

### 複数のデバイス

スマートフォン、タブレット、Android TV、PC：**各端末には、開発者機能が承認された専用の eWeLink アカウントと、そのアカウント自身の API キー（App ID / Secret）が必要です**。eWeLink は 1 アカウントにつき 1 台しかログインできません。eWeLink アプリで追加アカウントにデバイスを共有してください。Tuya のキーは複数の端末で使えます。詳細： [English](docs/guide/ewelink.en.md#using-several-devices-phone-tablet-android-tv) · [Türkçe](docs/guide/ewelink.tr.md#birden-fazla-cihazda-kullanım-telefon-tablet-android-tv)

### デモ

- **デモデバイス** — 全機能を試せる仮想デバイス。デバイス本体で何かが起きた（誰かが操作した、停電やWi-Fi切断が起きた）かのように動作するため、ルールが適用されアラームが鳴ります。上のボタンでの操作はご自身の操作として扱われ、アラームは鳴りません。

## すべての設定

以下はすべてアプリでの表示順です。**設定** タブには接続とアプリのオプションがあり、アラーム、サイレント時間、Telegram、スマートアラートは **アラート** タブ → アラート設定 にあります。デバイスごとのオプションは各デバイスのページにあります。

### 設定 → アカウント

| 設定 | 内容 |
|---|---|
| eWeLink — eWeLinkでログイン | eWeLink 自身のサインインページを開きます。アプリがパスワードを見ることはありません。 |
| API認証情報 | eWeLink 開発者アプリの App ID、App Secret、リージョン。 |
| ログアウト | 監視が停止します。設定と履歴は保持されます。 |
| Tuya / Smart Life | Tuya CloudプロジェクトのAccess IDとAccess Secretを入力してください（platform.tuya.com → Cloud → プロジェクト → Overview）。Smart Life / Tuyaアプリのアカウントがプロジェクトにリンクされている必要があります。データセンター: 中央ヨーロッパ, アメリカ西部, 中国, インド |
| 切断 | Tuya との接続を解除します。Tuya デバイスは監視されなくなります。 |
| デモデバイス | 全機能を試せる仮想デバイス |

### 設定 → 監視

SwitchGuardがバックグラウンドでデバイスを見守る方法です。

| 設定 | 内容 |
|---|---|
| 最大の信頼性 | プロセッサを常にスリープさせず、イベントが遅れないようにします。バッテリー消費が増えます。 |
| 短時間の切断を無視 | デバイスがオフラインになったことを通知するまで、この時間だけ待機します。その間に復帰した場合は通知しません。 |
| 監視停止時に警告 | インターネットまたはクラウドに、この時間接続できない場合に警告します |
| バックアップ確認の間隔 | 即時更新を利用できない場合のみ使用します。 |

### 設定 → 権限

これらがないと、Androidによってアラームが届かなくなる場合があります。

| 設定 | 内容 |
|---|---|
| 通知 | アラームや警告を表示できません。 |
| バックグラウンド動作 | スマートフォンが監視をスリープさせることがあり、アラームが遅れたり届かなかったりする可能性があります。 |
| 全画面アラーム | スマートフォンがロックされていると、アラームの大きな画面を開けません。 |
| ロック画面アラーム（Xiaomi） | スマートフォンがロックされていると、アラーム画面を開けません。「修正」をタップして「その他の権限」を開き、「ロック画面に表示」と「バックグラウンド実行中に新しいウィンドウを開く」をオンにしてください。 |
| 他のアプリの上にアラームを表示 | Android TVで、再生中の画面の上にアラームを表示するために必要です。タップしてSwitchGuardを許可してください。 |
| バックグラウンド起動（Xiaomi, Huawei, OPPO, vivo…） | バックグラウンド起動をブロックする端末（Xiaomi、Huawei、OPPO、vivo…）で表示：再起動や更新の後に監視が再開できるようにします。トラブルシューティングを参照。 |

### 設定 → 位置情報とゾーン

| 設定 | 内容 |
|---|---|
| 位置情報 | 日の出・日の入りや外気温のルールに必要です。位置情報はこのデバイス内に保存され、気温の取得時のみ約100 m単位に丸めてOpen-Meteoに送信されます。 |
| ゾーン | 地図上でエリアを選ぶと、スマートフォンがそのエリアに入ったとき、または出たときにオートメーションが実行されます（例: 帰宅したら庭の照明をつける、外出したらすべて消す）。地図画像はOpenStreetMapからダウンロードされ、位置情報はこのスマートフォン内でのみ使用されます。 |

### 設定 → スタンバイ画面

| 設定 | 内容 |
|---|---|
| スタンバイ画面を開く | 画面をタップすると「アプリを開く」と「閉じる」が表示されます |
| スクリーンセーバーとして使用 | Androidの設定が開きます。スクリーンセーバーでSwitchGuardを選び、充電中に開始するよう設定してください。充電器に接続中は、ボードがロック画面の代わりに表示されます。 |
| 夜間は暗くする | 23:00から7:00の間、文字が薄くなります |

### 設定 → 日次サマリー

| 設定 | 内容 |
|---|---|
| 日次サマリー通知 | 各デバイスのオン回数、オン時間、今日の消費電力量をお知らせします |
| 送信時刻 | サマリーを送る時刻。 |
| 今日のサマリーを今すぐ表示 | 今すぐ表示します。 |

### 設定 → バックアップと転送

| 設定 | 内容 |
|---|---|
| ファイルにバックアップ | ルール、オートメーション、設定、TuyaとeWeLinkのキーをパスワード付きファイルに保存します |
| ファイルから復元 | 新しいスマートフォンに移行しますか？バックアップファイルを選んでパスワードを入力してください |
| 別のデバイスに送信 | 同じWi-Fi上のテレビやタブレットに、Tuyaのキー、ルール、設定をコピーします |
| 別のデバイスから受信 | Wi-Fi経由でスマートフォンから設定を取り込みます |

Wi-Fi 転送では eWeLink の API キーや eWeLink セッションは決して送られません。もう一方の端末では、その端末自身の API キーを入力し、その端末自身の eWeLink アカウントでサインインしてください。一方、ファイルへのバックアップには eWeLink と Tuya のキーが含まれ、パスワードで保護されます。

### 設定 → 言語

| 設定 | 内容 |
|---|---|
| 言語 | アプリ、通知、アラームの言語を選択します。端末の言語、または 20 言語のいずれか（2.26 以降）。 |

### アラート → アラートカテゴリ

すべてのデバイスにはアラートカテゴリがあります。選択しない限り自動で設定されます: いずれかのイベントがアラームに設定された監視中のデバイスは「重要」、通知のみは「やや重要」、それ以外は「通常」です。条件付きアラートやオートメーションでは、カテゴリをトリガーに使えます（例: 「重要なデバイスがオフラインになったらアラームを鳴らす」）。

| 設定 | 内容 |
|---|---|
| 重要 · やや重要 · 通常 · 自動 | 自動の場合: いずれかのイベントがアラームを鳴らすなら「重要」、通知のみなら「やや重要」 |
| サイレント時間中も鳴らす | サイレント時間中もアラームが鳴ります / サイレント時間中、アラームは通知になります |

### アラート → サイレント時間

| 開始 / 終了 | サイレント時間の開始・終了時刻。 |

サイレント時間中も鳴らすよう設定したアラートカテゴリ（既定では「重要」）のデバイスは、引き続き鳴動します。

| オフにする | Telegram での通知をオフにします。 |

### アラート → スマートアラート

すべてのデバイスをまとめて見るアラートです: 停電、いつもと違う消費量、週次サマリー。Telegramでは、状況の確認、アラームの引き継ぎ、デバイスの遠隔操作もできます。

| 設定 | 内容 |
|---|---|
| 停電: 停電を検出 | 監視中のすべてのデバイスが同時にオフラインになると、デバイスごとではなく1件の「停電」アラートが届き、電力が戻ったときに継続時間のメッセージが届きます。 |
| 充電器を電源センサーとして使用 | このスマートフォン／タブレットを設置場所で常時接続しておけば、1分間充電器が抜けた状態を停電として扱います。インターネットが使えなくても動作します。メッセージはモバイルデータ経由でTelegramに送信されます。 |
| 在宅 / 外出: 在宅中はアラートを控えめに | 在宅中は、重要でないデバイスのアラームが通知になります（サイレント時間と同様）。重要なデバイスは常に鳴動します。 |
| バケーションモード | 外出扱いになり、サイレント時間はオフになり、毎朝9:00にレポートが届きます。自動的に終了します。 |
| 消費量: いつもと違う消費量 | 毎朝、昨日を直前2週間と比較します。使用量が大幅に多い場合は故障、大幅に少ない場合（ほとんど動いていない冷凍庫など）は停止の可能性があります。 |
| 電気料金プラン | 専用の料金がないデバイスに使う既定の料金です。3段階料金では、各時間がそれぞれの時間帯の料金で計算されます: 昼間6〜17時、ピーク17〜22時、夜間22〜6時。 |
| 月間予算 | 電力計測機能付きデバイスの推定コストがこの金額に達すると、月に1回通知します。 |
| 週次レポート | 毎週月曜9:00に、過去1週間の停電、アラームと応答時間、切断、消費量をお知らせします。設定済みの場合はTelegramにも送信されます。 |
| 今週のレポートを表示 | 今すぐ表示します。 |
| Telegram: コマンドと「了解」ボタン | リストの人は /status を送信したり、鳴動中のアラームを引き継いだりできます。アラームのメッセージには「了解」ボタンが付き、押すとスマートフォンが消音されます。 |
| デバイスのオン・オフを許可 | /on と /off コマンドです。リストの人だけが使えます。 |
| 段階的な通知 | それぞれの人に、個別に設定した待ち時間の後にメッセージを送ります。例: 近所の人には5分後、親戚には15分後、家族グループには30分後。誰かが「了解」をタップすると、次の人にはメッセージを送りません。 |
| 重要アラームで電話をかける | 「重要」カテゴリのデバイスがアラームを鳴らし、段階的アラートでの待ち時間が経過すると、このスマートフォンの回線からその人に電話もかけます。電話は起こすためだけのもので、状況は同時に送信されるTelegramメッセージに記載されます（Androidでは、アプリが通話中に音声を流すことはできません）。この番号を「SwitchGuardアラーム」として登録してもらってください。電話は2分ごとに最大3回、アラームが止められるか、誰かがTelegramで「了解」をタップするまで繰り返されます。グループには電話できません。 |
| スマートアラートをTelegramに送信 | 停電、いつもと違う消費量、予算アラート、週次レポートもTelegramに送信されます。 |
| ウォッチドッグ | 同じボットを使う2台のデバイス（スマートフォンとTVボックスなど）が互いを見守ります。送信側のデバイスはTelegramチャットのピン留めメッセージを更新し続け、見守る側は、それが止まるとアラームを鳴らして連絡先にメッセージを送ります。そのメッセージのピン留めを外さないでください。 |

## Telegram コマンド

リストの人は /status を送信したり、鳴動中のアラームを引き継いだりできます。アラームのメッセージには「了解」ボタンが付き、押すとスマートフォンが消音されます。

```
SwitchGuardコマンド:
/status – 監視、アラーム、デバイスの状況
/ack – 鳴動中のアラームを引き継ぐ
/on 名前 [チャンネル] – デバイスまたはグループをオン（複数: /on kitchen, garden）
/off 名前 [チャンネル] – デバイスまたはグループをオフ
/watt [名前] – 現在・今日の電力と通常の消費量
/temp – 外気温
/scene 名前 – シーンを実行
/home · /away – 在宅 / 外出に設定

自由な文章でも指示できます（英語またはトルコ語）: “turn off kitchen and garden”、“heater watts”、“is the pump on”。

デバイスのオン・オフやシーンの実行は、アプリで許可しておく必要があります（アラート → スマートアラート）。
```

英語とトルコ語のコマンド名のどちらも使えます（例：/status = /durum、/on = /ac）。コマンドは選んだチャットからのみ受け付けます。

## 権限とその理由

| 権限 | 理由 |
|---|---|
| `POST_NOTIFICATIONS` | アラーム、通知、監視状態を表示するため。 |
| `FOREGROUND_SERVICE` | 監視をバックグラウンドで動かし続けるため（常駐の状態通知）。 |
| `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | アラームが遅れないよう、バッテリー最適化の対象外にしてもらうため。 |
| `USE_FULL_SCREEN_INTENT` | ロック画面の上にアラームを全画面で開くため。 |
| `SYSTEM_ALERT_WINDOW` | ほかのアプリの上にアラームを表示するため（Android TV、Xiaomi）。 |
| `WAKE_LOCK` | イベント処理中にプロセッサを起こしておくため（「最大の信頼性」）。 |
| `VIBRATE` | アラーム中のバイブレーション。 |
| `RECEIVE_BOOT_COMPLETED` | 端末の再起動後に監視を再開するため。 |
| `INTERNET` | eWeLink / Tuya クラウドと通信するため（使う場合は Telegram / Open-Meteo / OpenStreetMap とも）。 |
| `ACCESS_COARSE_LOCATION` | 日の出/日の入りと気温のルールで「このデバイスの位置情報を使用」をタップしたときだけ。 |
| `ACCESS_FINE_LOCATION` | ゾーン：到着 / 出発ルール用の正確なエリア。 |
| `ACCESS_BACKGROUND_LOCATION` | ゾーン：アプリを閉じていても到着・出発を検知するため（ゾーン作成時のみ確認）。 |
| `CALL_PHONE` | 「重要アラームで電話をかける」：入力した番号にこの端末の回線から電話をかけるため。 |

## プライバシー

- 独自のサーバーなし、分析・広告・トラッキングなし。データを販売・共有することはありません。
- キー、トークン、デバイス、ルール、設定、履歴（最大 2,000 件）はあなたの端末にだけ保存されます。
- アプリが通信するのは、接続したクラウド（eWeLink `*.coolkit.cc` / `*.coolkit.cn`、Tuya `openapi.tuya*.com`）と、使う場合に限り Telegram、Open-Meteo（気温と天気。位置は約 100 m に丸め）、OpenStreetMap の地図タイルだけです。
- eWeLink のパスワードは eWeLink 自身のページで入力するため、アプリが見ることはありません。
- アプリのデータは Android のクラウドバックアップから除外されます。ファイルへのバックアップはパスワードで保護され、Wi-Fi 転送はワンタイムコードで暗号化されて自宅のネットワーク内で完結します。

プライバシーポリシー全文: [Google Sites](https://sites.google.com/view/switchguard-privacy) · [docs/privacy-policy.md](docs/privacy-policy.md)

## トラブルシューティングとよくある質問

### アラームが遅れる / 鳴らない

| 問題 | 対処 |
|---|---|
| バックグラウンド動作が制限されています | スマートフォンが監視をスリープさせることがあり、アラームが遅れたり届かなかったりする可能性があります。 |
| 全画面アラームが許可されていません | スマートフォンがロックされていると、アラームの大きな画面を開けません。 |
| Xiaomiがアラーム画面をブロックしています | スマートフォンがロックされていると、アラーム画面を開けません。「修正」をタップして「その他の権限」を開き、「ロック画面に表示」と「バックグラウンド実行中に新しいウィンドウを開く」をオンにしてください。 |
| アラーム通知が抑えられています | 「アラーム」通知カテゴリの重要度が高に設定されていないため、アラームがポップアップ表示や全画面表示されません。 |
| サイレントモード: 完全な消音 | このモードではアラーム音も消音されます。 |
| アラーム音量が非常に小さい | スマートフォンのアラーム音量がゼロまたはゼロに近いため、SwitchGuardが聞こえない可能性があります。「修正」で「最大音量で鳴らす」をオンにします。 |
| 通知がオフです | アラームや警告を表示できません。 |
| このスマートフォンにSwitchGuardがもう1つあります | スマートフォンのデュアルアプリ（アプリのクローン）機能で、SwitchGuardの別のコピーが作成されています。2つのコピーが並行して動作すると、すべてのアラームが2回鳴り、同じeWeLinkアカウントを使うと互いにログアウトさせ合います。Xiaomiのスマートフォンでは、このコピーの権限もオフに見えることがあります。2つ目のコピーを削除してください: アイコン（小さなバッジが付いている方）を長押しして「アンインストール」をタップします。 |

### バックグラウンドアプリを止めるメーカー

| Huawei / Honor | 「アプリの起動」でSwitchGuardを「手動で管理」に設定し、自動起動、関連起動、バックグラウンド動作をオンにしてください。 |

| vivo / iQOO | SwitchGuardのバックグラウンド起動と、バックグラウンドでの高い電力消費を許可してください。 |

### その他の質問

**監視が止まり、サインアウトされたと表示される。**  
ヒント: eWeLinkは1アカウントにつき1セッションのみ許可します。スマートフォンごとに別のeWeLinkアカウントを用意し、eWeLinkアプリでデバイスを共有してください。

**共有された Tuya デバイスが表示されない。**  
共有されたデバイスが表示されませんか？Tuyaはご自身のホームにあるデバイスのみを一覧表示します。オーナーにSmart Lifeでホームメンバーとして追加してもらってください（Me → Home Management → Add Member）。

**Tuya デバイスが更新されなくなった。**  
Tuya Cloudのトライアルが期限切れのため、Tuyaデバイスは監視されていません。platform.tuya.com → Cloud → IoT Core → Extend trial period で延長してください。

**変化が遅れて届く / 即時更新が使えない。**  
このApp IDでは即時更新を利用できないため、定期確認を使用しています（間隔より短い変化は検出できない場合があります）

**Google Play 版と GitHub 版を切り替えられますか？**  
できますが、先にもう一方をアンインストールしてください（署名が異なります）。アンインストール前にファイルへバックアップし、あとで復元してください。

**誰も起こさずにアラームを試すには？**  
アラームを今すぐ試します。音あり／音なし、すぐ／10秒後を選べます

**消費電力が eWeLink / Smart Life アプリと違うのはなぜ？**  
消費量は、監視中に取得した電力値からSwitchGuardが計算するため、メーカーのアプリ（eWeLink、Smart Life）の値とわずかに異なる場合があります。

## Windows 版アプリ

SwitchGuard for Windows（10 / 11）は PC で同じ監視を行います。タスクトレイに常駐し、PC 上で全画面アラームを鳴らし、同じルール、オートメーション、Telegram 機能を共有します。ゾーン、ウィジェット、ウォッチ、電話発信はスマートフォンのみです。

### 機能

- 同じタブ：デバイス, アラート, オートメーション, 履歴, チャット, 設定。チャットの音声コマンドは Windows の音声入力を使います。
- トレイアイコン：開く、監視の開始 / 停止、アラーム停止、終了。ウィンドウを閉じても監視は止まりません。
- 全画面のアラームウィンドウ、内蔵サウンド（サイレン, ビープ, パルス, チャイム）または独自の WAV / MP3。
- スタンバイ画面と Windows のスクリーンセーバー：PC がアイドル状態になるとボードが開きます。
- 充電器につないだままのノート PC が停電センサーになります。
- GitHub からワンクリックで更新。設定とライセンスは保持されます。パスワード付きファイルへのバックアップ（スマートフォンでは復元不可）。

| Windows のスクリーンセーバーとして使う | パソコンが操作されていないとスタンバイ画面が開きます。マウスを動かすかキーを押すと閉じます |
| 待ち時間 | スタンバイ画面が開くまでにパソコンが操作されない時間 |
| Windows のスクリーンセーバー設定 | 例:「再開時にログオン画面に戻る」 |
| スタンバイ画面を開く | 全画面。Esc で閉じ、クリックで「アプリを開く」。開いている間は画面が消えません。 |
| 言語と外観: テーマ | ライト、ダーク、または Windows と同じ。 |

### Windows へのインストール

1. セットアップファイル (SwitchGuard-…-Kurulum.exe) をダブルクリックします。管理者権限は不要で、数秒でインストールされます。
2. Windows に「Windows によって PC が保護されました」(SmartScreen) と表示されたら、詳細情報 → 実行 を押します。アプリはまだ署名されていないため警告が出ます。
3. SwitchGuard はユーザーフォルダー (AppData › Local › SwitchGuard) にインストールされ、デスクトップとスタートメニューにショートカットを追加します。
4. Windows にサインインすると自動でトレイ (時計の横) に起動します。ウィンドウを閉じても止まりません。終了するにはトレイアイコン → 終了。
5. 設定 → アカウント でアカウントを追加します (Tuya と eWeLink の手順は下にあります)。
6. 別のパソコンへの移行: 古いパソコンで 設定 → バックアップと転送 → ファイルにバックアップ。新しいパソコンにインストールし、ファイルから復元してから、eWeLink に再度サインインします。
7. アンインストール: Windows の設定 → アプリ → インストールされているアプリ → SwitchGuard → アンインストール。
8. 新しいバージョンのインストール: まず古いバージョンをアンインストールし (手順 7)、新しいセットアップファイルを実行します。設定、アカウント、音は保持されます。（アプリの「更新」ボタンを使えば自動で行われます。）
